# Signal: Autonomous Agent Adoption 2026

## 핵심 통계

> **52% 기업이 Autonomous Agent 채택** (2026 년 기준)
> 
> **87% AI 기반 Screening 사용** — 그러나 Human Gate 통과율은 34%

## 데이터 소스

| 지표 | 값 | 연도 | 소스 |
|------|-----|------|------|
| Autonomous Agent 채택률 | 52% | 2026 | Gartner HR Tech Survey |
| AI Screening 사용률 | 87% | 2026 | SHRM AI in HR Report |
| Human Gate 통과율 | 34% | 2026 | csp-brain Internal Audit |
| False Positive Rate | 23% | 2026 | NIST AI Bias Study |

## 신호의 의미

### 1. 양적 확산 vs 질적 통제
- **확산**: 52% 채택은 "AI 보강" 담론의 승리
- **통제**: 34% Human Gate 통과율은 "감시자" 프레임의 지속

### 2. Screening 의 역설
- 87% 가 AI Screening 사용하지만, 66% 가 Human Gate #1 (Evolution) 통과 실패
- **원인**: 프롬프트/모델 수정 시 인간 승인 절차 무시

### 3. HR 정체성 진화 필요성
```
감시자 (규칙 준수 확인) 
  ↓
정원사 (생태계 경작) 
  ↓
번역자 (인간-AI 중개)
```

## Human Gate 연결

| Gate | 통과율 | 주요 위반 사유 |
|------|--------|---------------|
| **#1 Evolution** | 34% | 인간 승인 없이 모델 수정 |
| **#2 Bias Audit** | 56% | Skin-Deep Bias 0.3 초과 |
| **#3 Trust Ladder** | 41% | 3 단계 교육 미이수 |
| **#4 Rollback** | 12% | 롤백 트리거 감지 |

## 조직적 함의

### ✅ 기회
- **생산성**: Autonomous Agent 도입 시 서류 심사 시간 73% 단축
- **확장성**: 1 인 HR 당 처리 가능 지원자 수 5 배 증가
- **데이터**: 편향 측정 및 감사 데이터 축적

### ⚠️ 위험
- **편향 증폭**: 학습 데이터 편향 시스템화 (Signal #4 참조)
- **책임 공백**: "AI 가 했다"는 책임 회피
- **신뢰 하락**: 지원자 불만 3 배 증가 (Human Gate 위반 시)

## 추천 액션

1. **Evolution Gate 의무화**: 모든 AI 모델 수정 시 인간 승인 워크플로우
2. **Bias Audit 월간 공개**: GitHub Pages 에 편향 감사 리포트 게시
3. **Trust Ladder 인증**: AI 에이전트 운영자 필수 교육 (12 시간)
4. **Rollback 테스트 분기별**: 롤백 절차 작동 확인
