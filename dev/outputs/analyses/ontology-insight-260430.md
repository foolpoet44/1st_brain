# 온톨로지 구축과 지식체계 인사이트

## Compiled Truth

배수정 박사의 온톨로지 구축 통찰을 바탕으로 `csp-brain`이 단순 데이터 저장소를 넘어 '사고의 보조 도구'로 진화하기 위한 전략적 제안입니다. 핵심은 '지식의 명시화' 너머에 있는 '침묵하는 맥락(Silent Context)'과 '무지의 윤곽'을 관리하는 데 있습니다.

---

## 인사이트 요약

### 1. HybridRAG: 구조적 질서와 의미적 흐름의 공존

- **Graph 영역 (정적 질서)**: 위계와 인과관계가 명확한 지식(`frameworks/`, `tools/`). 출처 추적성과 논리적 완결성 중점.
- **Vector 영역 (의미적 흐름)**: 뉘앙스와 맥락이 중요한 파편(`signals/`, `notes/`). 의외의 연결(Serendipity) 창출 중점.

### 2. '비어 있음'의 온톨로지: 무지의 윤곽 그리기

- 온톨로지는 모르는 영역의 윤곽을 그려주는 도구여야 함.
- **실행**: LINT 프로토콜을 통해 연결되지 않은 공백이나 데이터 부족 영역을 명시적으로 시각화하여 '메타인지' 지원.

### 3. '인터뷰'를 통한 암묵지 포착 (Human-in-the-loop)

- HR의 진정한 가치는 문서화되지 않은 '직감'과 '장면'에 있음.
- **실행**: INGEST 시 Claude가 "어떤 장면에서 그렇게 느끼셨나요?"와 같은 후속 질문을 던져 암묵지를 명시화.

### 4. 시간의 차원: 지식의 퇴적과 변천

- 지식의 '결과'뿐만 아니라 '변천 과정'이 HR 의사결정의 핵심 근거가 됨.
- **실행**: Timeline 구조를 강화하여 특정 시점의 판단 배경(시대적 맥락) 보존.

### 5. 사고의 보조 도구로서의 위치

- 데이터 기반의 외양에 속아 '보이지 않는 영역'을 놓치는 오만 경계.
- **결론**: `csp-brain`은 자동화 엔진이 아닌, CSP님이 더 깊은 사고를 할 수 있도록 돕는 '생각의 지형도'가 되어야 함.
