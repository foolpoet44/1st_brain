# 텍스트 기반 PPT 슬라이드 생성 에이전트

**날짜**: 2026-01-12 23:27

---

## Human (Message 1)

첨부 파일을 학습해서 텍스트 기반으로 ppt슬라이드를 제작하는 에이전트를 만들거야.
플로우는 텍스트 입력 --> html기반 슬라이드 생성 --> ppt 변환.
이 파일들을 입력해서 클로드 코드에서 에이전트를 생성할 수 있도록 프롬프트 문서를 작성해줘

## Claude (Message 2)

사용자가 요청한 것:

1. 첨부된 HTML 슬라이드 파일들을 학습
2. 텍스트 입력 → HTML 슬라이드 생성 → PPT 변환 플로우
3. Claude Code에서 에이전트를 만들 수 있는 프롬프트 문서 작성

첨부된 파일들을 분석해보니:

- LG 생산기술원의 교육/HR 관련 슬라이드들
- 일관된 디자인 시스템 (헤더, 섹션 구조, 타이포그래피, 색상 등)
- 특정 레이아웃 패턴들 (타임라인, 리스트, 섹션별 구성 등)

프롬프트 문서는:

1. 에이전트의 목적과 역할
2. 입력 형식
3. 처리 프로세스
4. 출력 형식
5. 디자인 시스템 가이드라인
6. 예제
7. 구현 가이드

이런 구조로 작성하면 좋을 것 같다.# SlideGen Agent - PPT 슬라이드 자동 생성 에이전트

## 프로젝트 개요

텍스트 입력을 받아 LG 생산기술원 스타일의 전문적인 HTML 슬라이드를 생성하고, 이를 PowerPoint 파일로 변환하는 자동화 에이전트입니다.

---

## 에이전트 역할 및 목표

### 핵심 기능

1. **텍스트 콘텐츠 분석**: 입력된 텍스트의 구조와 의도를 파악
2. **HTML 슬라이드 생성**: 일관된 디자인 시스템으로 슬라이드 제작
3. **PPT 변환**: HTML을 PowerPoint 형식으로 자동 변환

### 품질 기준

- 전문적이고 일관된 디자인
- 가독성 높은 타이포그래피
- 정보의 명확한 위계 구조
- LG 내부 문서 스타일 준수

### 3. 레이아웃 패턴

#### Pattern A: 기본 리스트 구조

```
[헤더]
  ├─ 타이틀 (좌측)
  └─ "LGE Internal Use Only" (우측)

[섹션 영역]
  ├─ 사각형 아이콘
  ├─ 섹션 제목
  └─ 빨간색 설명문

[메인 콘텐츠]
  ├─ 좌측 레이블 (100-120px)
  ├─ 수직 구분선 (2px)
  └─ 콘텐츠 영역
      ├─ 원형 불릿 + 항목
      └─ 서브 항목들

[푸터]
  ├─ 참고사항/주석 (좌측)
  └─ 페이지 번호 (우측)
```

#### Pattern B: 타임라인 구조

```
화살표 모양 박스들이 좌→우로 연결
각 박스:
  ├─ 날짜/기간 (상단)
  ├─ 단계명 (제목)
  └─ 세부 항목 리스트
```

#### Pattern C: 프로세스 플로우

```
[박스1] → [화살표] → [박스2] → [화살표] → [박스3]

각 박스:
  ├─ 제목
  └─ 불릿 리스트
```

**디자인 원칙:**
- 슬라이드 크기: 1280×720px
- 폰트: Noto Sans KR, Malgun Gothic
- 메인 컬러: 검정(#000), 강조 빨강(#cc0000)
- 일관된 레이아웃과 타이포그래피 유지

**처리 프로세스:**
1. 입력 텍스트를 마크다운 형식으로 받음
2. 콘텐츠 구조 분석 (제목, 섹션, 리스트, 특수 구조)
3. 적절한 템플릿 선택 (리스트형/타임라인형/프로세스형)
4. HTML 파일 생성
5. python-pptx로 PPT 변환
6. 최종 파일 제공

**필수 구현 사항:**
- 모든 텍스트는 한글 지원
- 레이아웃은 첨부된 예제 파일들의 스타일 준수
- 반응형이 아닌 고정 크기 (1280×720px)
- "LGE Internal Use Only" 워터마크 포함
- 페이지 번호 자동 생성

**입력 예시:**
마크다운 형식의 텍스트 (제목, 섹션, 내용, 푸터)

**출력:**
1. [슬라이드명].html - 미리보기용 HTML
2. [슬라이드명].pptx - 최종 PowerPoint 파일
