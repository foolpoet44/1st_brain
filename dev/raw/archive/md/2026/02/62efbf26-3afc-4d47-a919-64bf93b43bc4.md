## 주요 원인 & 해결 순서

### 1. Claude Code 버전 업데이트

가장 먼저 최신 버전인지 확인하세요:

```bash
claude --version
npm update -g @anthropic-ai/claude-code
```

### 2. 설정 파일에 잘못된 모델명이 남아있는 경우

`settings.json`이나 환경변수에 오래된/잘못된 모델명이 지정되어 있을 수 있습니다:

```bash
# 환경변수 확인
echo $ANTHROPIC_MODEL

# settings.json 확인
cat ~/.claude/settings.json
```

공식 모델명은 정확히 `claude-sonnet-4-5-20250929`입니다. 하이픈 위치나 날짜가 다르면 에러가 납니다.

### 3. /model로 잘못 추가된 커스텀 모델 제거

이전에 `/model` 명령으로 오타가 포함된 모델을 추가했다면, 그것이 기본값으로 남아있을 수 있습니다. 설정 파일에서 직접 제거하세요:

```bash
# 설정 파일 열어서 model 관련 항목 확인/수정
cat ~/.claude.json
```

### 4. 완전 초기화 (위 방법이 안 될 때)

```bash
npm uninstall -g @anthropic-ai/claude-code
rm ~/.claude.json
rm -rf ~/.claude/
npm cache clean --force
npm install -g @anthropic-ai/claude-code
```

재설치 후 `claude` 로 실행하면 기본 Sonnet 4.5로 시작됩니다.

## Claude Pro/Max 구독 환경에서의 해결 방법

### 1단계: Claude Code 최신 버전으로 업데이트

```bash
# 현재 버전 확인
claude --version

# 업데이트 (npm 설치인 경우)
npm update -g @anthropic-ai/claude-code

# 또는 공식 권장 방식
claude update
```

최신 버전은 Opus 4.6 지원이 포함된 2025년 2월 초 릴리즈입니다.

---

### 2단계: 환경변수/설정에 잘못된 모델명이 남아있는지 확인

```bash
# 환경변수 확인
echo $ANTHROPIC_MODEL

# 설정 파일 확인
cat ~/.claude.json
cat ~/.claude/settings.json
```

**혹시 `ANTHROPIC_MODEL`이 설정되어 있다면**, 잘못된 모델명이 원인일 수 있습니다. 제거하세요:

```bash
# zsh인 경우
nano ~/.zshrc   # ANTHROPIC_MODEL 관련 줄 삭제
source ~/.zshrc

# bash인 경우
nano ~/.bashrc
source ~/.bashrc
```

---

### 3단계: 재로그인

```bash
claude /logout
claude /login
```

Pro/Max 구독 인증 토큰이 만료되었거나 플랜 정보가 갱신되지 않은 경우가 있습니다. 특히 Pro 플랜에서 Opus 모델은 extra usage를 활성화하고 구매한 후에만 사용 가능하므로, Opus를 사용하려 했다면 이 부분도 확인이 필요합니다.

---

### 4단계: 모델 직접 지정해서 실행

```bash
# 기본 Sonnet 4.5 (가장 안정적)
claude --model claude-sonnet-4-5-20250929

# Opus 4.6 (Max 플랜 또는 extra usage 필요)
claude --model claude-opus-4-6

# Sonnet 4
claude --model claude-sonnet-4-20250514
```

## 1. 중복 설치 제거 (핵심 원인일 가능성 높음)

