## 에이전트 설계 구조

### 아키텍처: 3-Layer 분리

이 에이전트의 핵심 설계는 **입력 레이어 → 프롬프트 엔지니어링 레이어 → 렌더링 레이어** 3단 분리입니다.

**입력 레이어 (사이드바)** — 사용자가 건드리는 전부입니다. 페이지 유형 4가지, 제목/부제목/이어브로우/조직명 필드, 마크다운 자유 입력창, 고급 설정(테마/강조색/뒤로가기 URL/추가 지시사항). 마크다운 입력창은 의도적으로 넓게 잡았는데, "잘 쓴 마크다운 개요 = 잘 만들어진 HTML"이라는 일대일 관계를 사용자가 체득하게 만들기 위해서입니다.

**프롬프트 엔지니어링 레이어 (`buildSystemPrompt`)** — 여기가 에이전트의 실제 "뇌"입니다. 페이지 유형별로 완전히 다른 구조 가이드를 동적으로 주입합니다. 포털은 4열 카드 그리드와 Stats Row를, 콘텐츠 상세는 DO/DON'T 2컬럼 박스를, 로드맵은 타임라인 Phase 카드를, 가이드는 단계별 넘버링을 지시합니다. CSS 변수값(강조색, 테마 배경)도 시스템 프롬프트에 하드코딩이 아닌 동적으로 삽입되어, 사용자가 색상을 바꾸면 AI가 다른 팔레트로 생성합니다.

**렌더링 레이어** — 생성된 HTML을 `srcdoc`으로 iframe에 주입합니다. 코드 탭은 그대로 `pre` 태그로 보여주고, 다운로드는 Blob URL 방식으로 파일명을 자동 생성합니다.

---

### 핵심 의사결정 3가지

**① 예시 4개를 내장한 이유** — "빈 캔버스 공포"를 없애기 위해서입니다. 포털/콘텐츠/로드맵/가이드 각각의 실제 LG PRI 맥락 예시를 클릭 한 번으로 사이드바에 자동 채워주는 방식으로, 처음 쓰는 팀원도 "아, 이렇게 쓰면 되는구나"를 바로 체험합니다.

**② 생성 기록 5개 유지** — 세션 내에서 여러 버전을 비교할 수 있게 합니다. 예를 들어 "포털 다크블루 버전"과 "포털 레드 테마 버전"을 교대로 클릭하며 비교 가능합니다.

**③ max_tokens: 8000 설정** — 로드맵 페이지처럼 복잡한 구조는 4000으로는 잘리는 경우가 생깁니다. 8000으로 넉넉히 확보했습니다.

### 웹서버 배포 시 주의사항

이 에이전트 자체는 단일 HTML 파일이라 어디서든 실행됩니다. 단, Anthropic API는 클라이언트 사이드에서 직접 호출하는 구조라, **CORS 이슈 없이 동작하는 대신 API 키가 노출**됩니다. 내부 인트라넷 or SharePoint 배포라면 이 구조로 충분하지만, 외부 공개 서버라면 Node.js 백엔드 프록시로 키를 서버사이드에 숨기는 것을 권장합니다.

## 해결 방법 3가지

어떤 환경을 원하시는지에 따라 달라집니다.

**옵션 A: Claude.ai Artifact 내장 API 활용 (지금 바로 가능)**
Claude.ai 환경에서는 API 키 없이 Claude를 호출할 수 있는 내장 API가 지원됩니다. 에이전트를 Artifact 방식으로 재구현하면 키 없이 동작합니다. **가장 빠르고 SharePoint 배포와도 무관하게 Claude.ai 안에서 쓸 수 있습니다.**

**옵션 B: 키 입력창 추가 (현재 파일 최소 수정)**
에이전트 UI에 API 키 입력 필드를 추가합니다. 사용자가 본인 키를 직접 입력하는 방식으로, 배포 파일 자체에는 키가 없습니다. 내부 팀 전용이라면 실용적입니다.

**옵션 C: 백엔드 프록시 서버 (웹서버 배포 시 정석)**
Node.js 또는 Python 서버가 키를 서버사이드에 보관하고 프론트엔드는 프록시를 통해 호출합니다. 보안상 가장 올바른 방식이지만 서버 운영이 필요합니다.

이 `.jsx` 파일을 Claude.ai에서 실행하려면 두 가지 방법이 있습니다.

**방법 1: 이 대화에서 바로 실행 (가장 빠름)**

지금 이 채팅창에 다음 메시지를 보내세요:

> "위 jsx 파일 내용을 Artifact로 실행해줘"

그러면 Claude가 React Artifact로 렌더링해서 즉시 키 없이 사용 가능합니다.

**방법 2: 새 대화에서 재사용**

jsx 파일을 첨부하거나 코드를 복사해서 새 대화에 붙여넣은 후 "이걸 Artifact로 실행해줘"라고 하면 됩니다.

## 왜 키가 필요 없는가 — 한 줄 요약

Claude.ai Artifact 환경은 `api.anthropic.com`으로의 `fetch` 요청을 인터셉트해서 현재 로그인한 사용자의 세션 권한으로 자동 처리합니다. API 키를 코드에 넣지 않아도 Claude.ai를 사용 중인 계정의 인증이 투명하게 적용되는 구조입니다. 웹서버 독립 배포가 필요해지는 시점, 즉 팀 전체가 자신의 Claude.ai 계정 없이 접근해야 할 때는 옵션 B/C로 전환하면 됩니다.
