## 성과의 재정의: 3가지 확장 관점

**결과 너머의 프로세스 품질**
기존 평가가 '무엇을 달성했나'에 집중했다면, 이제는 '어떻게 달성했나'를 함께 봐야 합니다. 예를 들어 프로젝트 완수율 외에 '의사결정 사이클 타임(Decision Cycle Time)'을 측정할 수 있습니다. 아이디어 제안부터 실행 결정까지 걸리는 시간, 주요 이슈 발견부터 해결까지의 속도 등이죠. 제조업 맥락에서는 '문제 해결 리드타임'도 좋은 지표입니다 - 품질 이슈 식별 후 근본원인 규명까지 소요 시간, 개선안 도출 및 적용 속도 등을 트래킹하는 거죠.

**현재 성과와 미래 역량의 균형**
단기 실적만이 아니라 팀의 지속가능성을 함께 봐야 합니다. '지식 자산 축적도'를 측정해보세요. 팀 내 문서화된 노하우 증가율, 크로스 트레이닝 완료율, 핵심 업무의 백업 인력 보유 비율 같은 것들이죠. LG PRI 같은 연구조직에서는 '기술 부채 관리 지수'도 유용합니다. 레거시 프로세스/시스템 개선 투자 비율, 표준화/자동화 진행률 같은 지표로 미래 생산성을 가늠할 수 있습니다.

**내부 효율성과 외부 영향력의 통합**
팀 내 성과뿐 아니라 조직 전체에 미친 파급효과를 봐야 합니다. '협업 임팩트 스코어'로 타팀 요청 대응 만족도, 공유한 Best Practice의 타 부서 적용 건수, 부서간 프로젝트 기여도 등을 측정할 수 있습니다.

## 측정 가능한 세부 지표 예시

**프로세스 혁신 지표**

- 반복 업무 자동화율: 월간 처리 업무 중 자동화된 비율
- 프로세스 간소화 지수: 단계 축소, 승인 라인 감소 등의 개선 건수
- 실시간 데이터 활용률: 의사결정 시 당일 데이터 활용 비중

**학습 및 성장 지표**

- 역량 포트폴리오 다양성: 팀원당 보유 스킬 평균 개수 및 분포
- 지식 공유 활성도: 사내 위키 기여 건수, 스터디/세미나 운영 횟수
- 외부 벤치마킹 빈도: 타사 사례 연구, 컨퍼런스 참석 등

**조직 건강성 지표**

- 심리적 안전감 수준: 정기 서베이 기반 측정
- 업무 자율성 체감도: 의사결정 권한 위임 체감 정도
- 번아웃 예방 지수: 초과근무 패턴, 휴가 사용률, 업무 몰입도 조합

**디지털 전환 기여도** (DX 업무 맥락)

- 데이터 기반 의사결정 비율: 직관이 아닌 데이터 근거 제시 빈도
- AI/자동화 도구 활용도: 신규 도구 도입 및 정착 건수
- 디지털 리터러시 향상도: 팀원 디지털 스킬 레벨 상승률

3. **복합 지표** (여러 데이터 소스 통합)

각 지표는:

- 측정 방법이 명확해야 함
- HR 시스템에서 자동 수집 가능하면 더 좋음

## 1. 목표 달성 차원 (40%)

**정량 지표**

- **목표 달성률**: 설정 KPI 대비 실적 (기존 방식)
- **목표 난이도 계수**: 목표 설정 시 Stretch 수준 반영 (1.0~1.5배 가중)
- **중간 점검 개선도**: 상반기 → 하반기 성과 개선 폭
- **돌발 과제 대응률**: 계획외 긴급 업무 완수 비율

**측정 방법**

```
최종 점수 = (달성률 × 난이도 계수 × 0.7) + (개선도 × 0.2) + (돌발 대응률 × 0.1)
```

## 2. 업무 프로세스 품질 차원 (25%)

**정량 지표**

- **업무 정시 완료율**: 마감일 준수 비율
- **재작업률**: 피드백 후 수정 횟수 (낮을수록 높은 점수)
- **커뮤니케이션 효율성**:
  - 이메일 응답 평균 시간 (24시간 내 응답률)
  - 회의록 작성/공유 완료율
  - 업무 투명성 점수 (팀 공유 문서 업데이트 주기)

**정성 평가 (구조화)**

- **다면평가 - 협업 품질**: 상사/동료/타부서 평가 (5점 척도)
- **의사결정 질**: 리더의 판단 평가 (논리성, 데이터 활용도, 위험 관리)

## 3. 조직 기여도 차원 (20%)

**정량 지표**

- **지식 공유 기여도**:
  - 사내 위키/시스템 등록 건수 및 활용도
  - 교육/멘토링 제공 시간 (분기별)
  - Best Practice 등록 및 타 팀 적용 건수

- **프로세스 개선 기여**:
  - 개선 제안 채택 건수
  - 개선안의 정량적 효과 (시간/비용 절감액)

- **Cross-Functional 협업도**:
  - 타 부서 프로젝트 참여 횟수
  - 협업 만족도 (타 부서 평가)

**측정 예시**

```
기여도 점수 = (지식공유 활동 × 2) + (개선 제안 효과 × 3) + (협업 평가 × 1)
```

## 4. 역량 성장 차원 (10%)

**정량 지표**

- **학습 활동**:
  - 사내외 교육 이수 시간
  - 자격증/전문성 인증 취득
  - 직무 관련 스터디 참여율

- **스킬 확장성**:
  - 신규 업무/기술 습득 건수
  - 담당 업무 범위 확대 정도

**정성 평가**

- **역량 레벨 상승**: 직무별 역량 모델 기준 레벨 업 평가
- **변화 대응력**: 신기술/신규 업무 적응 속도 평가

## 5. 리더십/팔로워십 차원 (5%)

**팀장급 (리더십)**

- **팀 성과 기여도**: 팀 전체 목표 달성률
- **팀원 성장 지원**: 팀원 평균 역량 상승률
- **조직문화 조성**: 팀 참여도, 이직률, Pulse Survey 점수

**팀원급 (팔로워십)**

- **주인의식**: 업무 선제 제안, 문제 발견 및 해결 주도성
- **팀 목표 정렬도**: 개인 성과가 팀 목표에 기여한 정도
- **긍정적 영향력**: 팀 분위기, 동료 지원 등 (동료 평가)

## HR 시스템 연계 자동 수집 가능 지표

**HRM 시스템에서 추출**

- 근태 정보: 정시 출퇴근율, 연차 사용 패턴
- 교육 이력: 이수 과정, 시간, 평가 결과
- 다면평가 결과: 리더십, 협업, 전문성 점수

**협업 도구에서 추출** (Notion, Teams, Slack 등)

- 문서 기여도: 작성/수정 건수, 조회수
- 커뮤니케이션 활동: 응답 속도, 멘션 빈도
- 프로젝트 참여: 태스크 완료율, 마일스톤 달성

**이메일/캘린더 시스템**

- 회의 시간 효율성: 회의 소요 시간 대비 산출물
- 외부 협업: 타 부서 미팅 빈도

## 평가 등급 산출 로직 예시

```python
# 가중치 적용 총점 계산
total_score = (목표달성 × 0.40) +
              (프로세스품질 × 0.25) +
              (조직기여 × 0.20) +
              (역량성장 × 0.10) +
              (리더십_팔로워십 × 0.05)

# 상대평가 적용 (팀 내 또는 직급별)
if total_score >= 90: grade = 'S'
elif total_score >= 80: grade = 'A'
elif total_score >= 70: grade = 'B'
elif total_score >= 60: grade = 'C'
else: grade = 'D'

# 보정 로직
- 핵심인재 Pool 포함 여부
- 리더 재량 조정 (±5점)
- 징계/윤리 이슈 감점
```

## 실무 적용 Tips

**단계적 도입 전략**
1년차: 기존 평가(70%) + 신규 지표(30%) 병행
2년차: 비중 조정 및 지표 정교화
3년차: 완전 전환 및 자동화

**데이터 수집 주기**

- 일일: 협업 도구 활동 로그
- 주간: 업무 진척도, 마일스톤
- 월간: Pulse Survey, 프로세스 지표
- 분기: 역량 평가, 다면평가
- 연간: 종합 평가 및 등급 산출

**공정성 확보 방안**

- 직무별 가중치 차등 적용 (연구직 vs 지원직)
- Calibration 세션 운영 (평가자간 편차 조정)
- 이의신청 프로세스 명문화

## Claude (Message 6)

사용자가 "tangible하지 않다"고 느낀다는 것은... 너무 추상적이고 이론적이라는 뜻이겠죠. HR 전문가로서 17년 경력에 실무자인데, 제가 제시한 것들이 너무 일반론적이고 실제로 "어떻게 측정하고 수집하고 판단하는지"가 구체적으로 안 보인다는 거네요.

Tangible하게 만들려면:

1. 실제 데이터 예시를 보여줘야 함
2. 측정 방법이 명확해야 함
3. 수집 도구와 방법이 구체적이어야 함
4. 판단 기준이 명확해야 함
5. 실제 케이스/시나리오로 보여줘야 함

사용자는 CSP이고, LG PRI에서 근무하며, 실제로 리더십 평가 프로그램을 운영하고 있고, HR 자동화 시스템을 개발하는 사람입니다. 그래서 더 구체적인, 실행 가능한 형태가 필요할 것 같아요.

"손에 잡히는" 느낌이려면:

- 실제 스프레드시트나 대시보드 화면처럼 보여주기
- 구체적인 숫자와 예시
- 실제 수집 방법 (어떤 시스템의 어떤 화면에서, 어떤 SQL 쿼리로)

**협업 임팩트 (실제 활동 기록)**


사용자가 직무별 세부 지표를 R&D와 Non R&D로 크게 이분화하여 단순화하길 원하는군요. 실무적으로 적용 가능한 명확한 구분이 필요할 것 같습니다.

R&D:

- 선행 R&D
- 연구 (Applied Research)

Non R&D:

- 영업
- 마케팅
- 오퍼레이션
- 그 외 지원 부서들

각각의 특성을 고려한 평가 프레임워크를 만들어야 합니다.

R&D의 특성:

- 장기적 성과
- 불확실성 높음
- 정량화 어려움
- 혁신/창의성 중요
- 지식 자산 축적

Non R&D의 특성:

- 단기 성과 명확
- 측정 용이
- 매출/비용 직접 연관
- 실행력/효율성 중요
- 즉각적 결과

사용자는 tangible하고 직관적인 지표를 원하므로, 복잡하지 않게 핵심만 추려야 합니다.좋습니다! **R&D vs Non R&D** 이분법으로 명확하게 단순화하겠습니다.

```
• 오류/클레임: 0건(15점) / 1~2건(12점) / 3~5건(9점)
• 재작업률: 5% 이하(15점) / 5~10%(12점) / 10% 초과(9점)
```

**4. 협업 기여 (5점)**

```
• 타부서 지원: 5회 이상(5점) / 3~4회(4점) / 1~2회(3점)
• 프로세스 개선 제안: 채택 2건 이상(5점) / 1건(3점)
```

### 등급 산정

```
B등급: 70~84점 (중위 50%)

```

```
- 목표 미달성 시 상한선: 최대 B등급
- 목표 초과 달성 시 가산점: 120% 이상 → +10점 보너스

- 일관성 보너스: 4분기 모두 목표 달성 시 +5점

✅ 예외 상황 처리
- 불가항력(시장 변화, 천재지변): 목표 재조정 가능
- 재조정은 상반기 1회, 하반기 1회만 허용
```

## Claude (Message 14)

사용자가 본질적인 질문을 던졌다. 지금까지 나는 다양한 지표들을 나열했지만, 정작 "성과란 무엇인가"라는 근본적인 정의를 먼저 하지 않았다.

사용자는 17년 HR 경력의 CSP로, 리더십 평가 프로그램을 운영하고 있고, 성과평가 체계를 고민하는 전문가다. 이런 분이 "원론적으로"라고 하면서 본질을 묻는다는 것은:

1. 지금까지 내가 제시한 것들이 너무 테크니컬하고 표면적이었다
2. 성과의 본질적 정의 없이 측정 방법만 나열했다
3. "무엇을 측정할 것인가"보다 "무엇이 성과인가"를 먼저 정립해야 한다

성과의 본질을 생각해보면:

- 조직 관점: 조직 목표 달성에 기여한 정도
- 개인 관점: 역할 기대치 대비 실제 수행 결과
- 시간 관점: 현재 결과 + 미래 역량
- 가치 관점: 산출물의 질적/양적 가치

하지만 더 깊이 들어가면:

- 성과 = Output인가? Outcome인가?
- 성과 = 개인의 것인가? 팀의 것인가?

- 성과의 본질은 측정 가능성과 계획성을 넘어선다. 예측하지 못한 혁신적 성과와 정량화되지 않는 가치도 중요하다.
- 성과는 단순한 결과물이 아니라, 조직과 개인의 잠재력을 드러내는 복합적인 개념이다.

HR 전문가의 깊이 있는 통찰을 위해, 성과를 다차원적 렌즈로 바라봐야 한다. 측정 가능한 것을 넘어 창발적이고 잠재적인 가치까지 포함하는 포괄적 관점이 필요하다.아, 핵심을 찌르셨네요. 지표만 나열하기 전에 **"성과의 본질"**을 먼저 정의해야 하는데 말이죠.

## 성과(Performance)의 본질적 정의

### 🎯 성과 = 무엇인가?

**일반적 정의의 한계**

```
"목표 대비 달성도" → 너무 협소함
"조직 기여도" → 너무 추상적임
"역량 발휘도" → 과정이지 결과가 아님
```

**본질적 관점에서 성과란:**

> **"조직이 원하는 가치(Value)를 창출하기 위해,**  
> **주어진 역할(Role)에서,**  
> **투입된 자원(Input) 대비,**  
> **산출한 결과물(Output)과 그로 인한 변화(Outcome)의 총합"**

---

## 성과를 구성하는 4가지 차원

### 1️⃣ **결과(Result)** - What을 달성했는가?

```
• 가시적 산출물: 매출, 제품, 특허, 보고서
• 정량적 지표: 목표 대비 달성률, 숫자로 표현 가능한 것
• 즉각적 측정 가능

예시:
- 영업: 연매출 ￦800M 달성
- R&D: 특허 3건 출원
- 생산: 불량률 0.8%
```

**하지만 결과만으로는 불충분:**

- 운이 좋아서 달성했을 수도
- 타인의 도움을 받았을 수도
- 미래를 희생하고 단기 성과만 냈을 수도

---

### 2️⃣ **과정(Process)** - How를 실행했는가?

```
• 업무 수행 방식: 효율성, 품질, 협업
• 의사결정의 질: 논리성, 데이터 활용, 리스크 관리
• 조직 문화 기여: 동료 지원, 지식 공유, 윤리

예시:
- 혼자가 아닌 팀과 협력해서 달성
- 단순 달성이 아닌 프로세스를 개선하며 달성
- 타인에게 해를 끼치지 않고 달성
```

**과정이 중요한 이유:**

- 지속가능성: 재현 가능한 방식인가?
- 학습 가능성: 다른 사람도 배울 수 있는가?
- 조직 건강성: 조직에 긍정적 영향을 미치는가?

---

### 3️⃣ **영향(Impact)** - 얼마나 중요한가?

```
• 파급 효과: 나의 성과가 조직 전체에 미친 영향
• 전략적 가치: 회사의 중장기 목표와의 정렬도
• 난이도: 같은 결과라도 난이도가 다름

예시:
- 매출 ￦100M: 신규 시장 진입 vs 기존 고객 재구매
- 특허 1건: 원천 기술 vs 개량 기술
- 불량률 개선: 0.1%p vs 3%p 개선
```

**같은 결과, 다른 가치:**

```
A사원: 루틴 업무 10건 완료 (예상된 결과)
B사원: 신규 프로세스 1건 구축 (파급효과 큼)

→ 양적으로는 A가 많지만, 질적으로는 B가 중요
```

---

### 4️⃣ **성장(Growth)** - 미래 가치는 얼마나 높아졌는가?

```
• 역량 향상: 개인의 역량 레벨업
• 조직 역량 축적: 팀의 노하우, 시스템 개선
• 지속성: 내년에도 더 나은 성과를 낼 수 있는 기반

예시:
- 혼자만 아는 업무 → 팀원에게 전수
- 엑셀 수작업 → 자동화 시스템 구축
- 개인 스킬 습득 → 조직 표준 프로세스화
```

**성장이 없는 성과의 문제:**

```
올해 매출 ￦1B 달성
→ 하지만 모든 노하우가 개인에게만 있음
→ 그 사람이 떠나면? 성과도 사라짐

vs

올해 매출 ￦800M 달성
→ 영업 매뉴얼 체계화, 신입도 따라할 수 있음
→ 내년엔 팀 전체가 ￦5B 달성 가능

→ 후자가 진정한 성과
```

## 성과의 2×2 매트릭스

```
                높은 Impact
                     ▲
                     │
        전략적 성과   │   혁신적 성과
        (중요하고     │   (중요하고
         새로운 것)   │    어려운 것)
                     │
─────────────────────┼─────────────────── 높은 Result
                     │
        루틴 성과    │   효율적 성과
        (해야 할     │   (잘 해낸
         일 완수)    │    기본 업무)
                     │
                 낮은 Impact
```

**4가지 성과 유형:**

**① 루틴 성과 (낮은 Result, 낮은 Impact)**

- 기본 업무 수행, 기대치 충족
- 예: 일일 보고서 작성, 정해진 미팅 참석
- 평가: C~B등급 (해야 할 일을 한 것)

**② 효율적 성과 (높은 Result, 낮은 Impact)**

- 양적으로 많이, 빠르게 처리
- 예: 목표치 120% 달성, 업무 처리 속도 향상
- 평가: B~A등급 (기대 이상 수행)

**③ 전략적 성과 (낮은 Result, 높은 Impact)**

- 당장 숫자는 적지만 미래 가치 큼
- 예: 신규 시장 개척, 장기 R&D, 조직 체질 개선
- 평가: A등급 (중요한 일을 한 것)

**④ 혁신적 성과 (높은 Result, 높은 Impact)**

- 양적으로도 많고, 질적으로도 중요
- 예: 신제품 출시로 매출 급증, 혁신적 기술 개발
- 평가: S등급 (기대 이상 + 중요한 일)

## HR 관점에서 성과를 정의하는 3가지 철학

### 철학 1: 성과 ≠ 개인의 것, 성과 = 조직의 것

```
개인주의적 관점:
"내가 얼마나 잘했는가?"
→ 스타 플레이어 육성, 개인주의 조장

조직주의적 관점:
"우리 조직이 원하는 가치를 내가 얼마나 창출했는가?"
→ 협업 강조, 조직 목표 정렬
```

**실무 적용:**

- 개인 목표는 반드시 팀/조직 목표와 연결
- 타인을 깎아내리며 달성한 성과는 감점
- 협업을 통한 시너지 창출을 가점

---

### 철학 2: 성과 ≠ 결과만, 성과 = 결과 + 과정 + 미래

```
단기 결과주의:
"올해 목표 달성했으면 OK"
→ 번아웃, 미래 희생, 조직 피폐화

장기 균형주의:
"올해 달성 + 내년도 가능성 + 조직 건강"
→ 지속가능성, 역량 축적, 조직 성장
```

**실무 적용:**

- 결과 50% + 과정 30% + 성장 20%
- 결과만 좋고 과정이 나쁘면 B등급 제한
- 성장이 있으면 결과가 부족해도 A등급 가능

---

### 철학 3: 성과 ≠ 측정된 것만, 성과 = 보이지 않는 기여 포함

```
측정 가능한 것만:
"숫자로 안 나오면 인정 안 함"
→ 쉬운 일만, 측정 가능한 일만 함

총체적 평가:
"보이지 않지만 중요한 기여도 인정"
→ 멘토링, 문화 조성, 위기 대응
```

**실무 적용:**

- 정량 70% + 정성 30%
- "Hidden Contribution" 항목 별도 평가
- 리더의 서술형 평가 필수

---

## 그렇다면 성과 평가란?

**성과 평가의 본질:**

> "조직이 원하는 가치를 창출하는 데 있어,  
> 이 사람이 얼마나 기여했는지를  
> 공정하고 객관적으로 측정하여,  
> 보상하고 성장시키는 프로세스"

**성과 평가가 해야 할 일:**

1. **측정**: 기여도를 숫자와 사실로 포착
2. **판단**: 그 기여가 얼마나 중요한지 가치 평가
3. **피드백**: 잘한 점, 부족한 점 명확히 전달
4. **보상**: 공정한 차등 보상으로 동기 부여
5. **개발**: 부족한 역량을 성장시킬 방향 제시

**성과 평가가 하지 말아야 할 일:**

1. **과거 심판**: 단순히 잘잘못 따지기
2. **서열 매기기**: 사람에 등급 붙이는 것이 목적
3. **정치적 도구**: 줄 서기, 눈 밖에 나면 불이익

   - 결과 중심? 과정 중심? 영향 중심?
   - 단기 중심? 장기 중심?

3. **측정되지 않지만 중요한 기여는 어떻게 포착하고 있나요?**
   - 리더의 주관? 동료 평가? 무시?

이 질문들에 대한 답을 먼저 정립하면,
그에 맞는 **지표 체계**가 자연스럽게 나올 것 같습니다.

어떻게 생각하세요?

## Claude (Message 16)

사용자가 현재 조직의 성과 정의에 대해 명확하게 답변했습니다:

1. 상급자의 목표달성 기여 정도
2. 결과중심/단기
3. 동료평가

이건 매우 전형적인 한국 대기업의 성과평가 시스템이네요.

사용자는 이제 이 현실을 기반으로, 어떻게 개선하거나 확장할지를 고민하는 것 같습니다.

이제 이 현실 진단을 바탕으로:

- 이 방식의 문제점
- 개선 방향
- 구체적인 대안

을 제시해야 할 것 같습니다.

사용자의 맥락을 고려하면:

- LG 같은 대기업
- HR 전문가로서 시스템 개선을 고민 중
- 온톨로지 기반 자동화를 추구
- 실무적이고 tangible한 접근 선호

따라서 이론적 비판이 아니라, 실무적 개선안을 제시해야 합니다.완벽한 진단입니다. 이제 문제가 선명해졌네요.

## 현재 시스템 진단

```
성과 = "상급자의 목표달성에 내가 얼마나 기여했는가"
초점 = 결과 중심 + 단기
보완 = 동료평가
```

이건 전형적인 **Top-down, 결과 중심, MBO 방식**입니다.

---

## 이 방식의 구조적 한계

### 🔴 문제 1: 상급자 목표 = 성과의 유일 기준

```
현상:
상급자 목표에 기여 → 높은 평가
상급자 목표 밖 활동 → 인정 안 됨

실제 사례:
• A사원: 상사 목표인 "매출 증대"에 집중 → A등급
• B사원: 회사에 중요한 "프로세스 혁신" 추진 → B등급
  (상사 목표에 없었음)

결과:
→ 중요하지만 상사 관심 밖 일은 아무도 안 함
→ 상사가 잘못된 목표 세우면 팀 전체가 헛일
→ 혁신보다 상사 눈치가 우선
```

---

### 🔴 문제 2: 결과 중심 + 단기

```
현상:
올해 숫자 → 평가됨
내년 기반 → 평가 안 됨

실제 사례:
• 영업팀: 단기 매출 위해 무리한 계약 → 올해 A등급
           → 내년 클레임 폭증, 고객 이탈

• R&D: 3년 과제 착수 → 올해 산출물 없음 → C등급
        → 의욕 상실, 연구 중단
        → 회사는 미래 기술 상실

결과:
→ 장기 투자 기피
→ 속 빈 강정식 성과
→ 조직 역량 고갈
```

---

### 🔴 문제 3: 동료평가로만 보완

```
현상:
정량 = 상급자 목표 기여도
정성 = 동료평가

실제 사례:
• 동료평가: "협업 잘함", "친절함" → 추상적
• 핵심 기여: "프로세스 개선으로 팀 전체 효율 20% 향상"
            → 측정 안 됨, 인정 안 됨

결과:
→ 동료평가 = 인기투표
→ 진짜 기여 vs 관계 관리 구분 안 됨
→ "착한 사람"이 높은 평가 (실제 기여와 무관)
```

## 이 시스템이 만들어내는 왜곡된 행동

### 1. 상사 목표에만 올인

```
✓ 상사 목표: 분기 매출 ￦500M
✗ 회사 목표: 신규 시장 진출

사원들:
→ 기존 고객에게만 영업 집중 (쉬우니까)
→ 신규 시장은 아무도 안 건드림 (어렵고 성과 안 나오니까)
→ 단기 매출은 달성, 장기 성장은 제로
```

### 2. 측정 가능한 것만 함

```
선택지:
A. 시스템 자동화 (올해 산출 없음, 내년부터 효과)
B. 수작업 반복 (올해 처리 건수 많음)

선택:
→ B 선택 (올해 평가에 유리)
→ A는 아무도 안 함
→ 조직은 영원히 수작업
```

### 3. 협업보다 개인 성과

```
상황:
동료가 어려운 프로젝트로 고생 중

선택지:
A. 도와줌 → 내 시간 소모, 내 성과 감소
B. 안 도와줌 → 내 목표에 집중, 높은 평가

선택:
→ B 선택 (합리적 선택)
→ 협업 문화 붕괴
→ 사일로 조직화
```

## 개선 방향: 3차원 성과 체계

### AS-IS: 1차원 평가

```
성과 = 상급자 목표 달성도 (70%) + 동료평가 (30%)
```

### TO-BE: 3차원 평가

```
┌─────────────────────────────────────┐
│ 1축: 목표 달성 (What)         40%  │
│    - 상급자 목표 기여              │
│    - 회사 전략 목표 정렬           │
├─────────────────────────────────────┤
│ 2축: 실행 품질 (How)          30%  │
│    - 효율성 (투입 대비 산출)       │
│    - 협업 기여도 (객관적 측정)     │
│    - 프로세스 개선                 │
├─────────────────────────────────────┤
│ 3축: 미래 기여 (Future)       30%  │
│    - 역량 성장 (개인)              │
│    - 조직 역량 축적 (지식자산)     │
│    - 지속가능성                    │
└─────────────────────────────────────┘
```

## 구체적 측정 방법

### 1축: 목표 달성 (40%) - 기존 유지하되 확장

**상급자 목표 (25%)**

```
기존대로 측정
- 상급자가 부여한 목표 달성률
```

**전략 목표 정렬 (15%)**

```
NEW: 회사/본부 전략 목표 기여도 측정

예시:
회사 목표: "DX 전환"
→ 개인이 디지털 도구 도입/확산 기여했는가?
→ 상급자 목표에 없어도 인정

측정:
- 전사 전략 과제 참여 건수
- DX 도구 도입/전파 건수
- 타부서 협업 프로젝트 기여
```

---

### 2축: 실행 품질 (30%) - 동료평가를 구조화

**효율성 (10%)**

```
기존: 동료평가로 "일 잘함" 체크
개선: 객관적 지표로 측정

측정:
- 일정 준수율: 마감 지킨 비율
- 재작업률: 피드백 후 수정 횟수
- 시간당 산출: 투입 시간 대비 결과물
```

**협업 기여 (10%)**

```
기존: 동료평가로 "협업 잘함" 체크
개선: 실제 행동 데이터로 측정

측정:
- 타팀 지원 건수 (요청 받은 것, 로그 추적)
- 문서/지식 공유 (Notion 기여도, 조회수)
- 멘토링/교육 (신입 지원, 세미나 제공)
- 응답 속도 (이메일, 메신저 평균 응답 시간)
```

**프로세스 개선 (10%)**

```
NEW: 일만 하는 것이 아니라 일하는 방식 개선

측정:
- 개선 제안 채택 건수
- 자동화 구축 (절감 시간 환산)
- 표준화/매뉴얼 작성
- 효과: 정량적 절감/개선 효과
```

---

### 3축: 미래 기여 (30%) - 완전 신규

**개인 역량 성장 (10%)**

```
측정:
- 신규 스킬 습득 (교육 이수, 자격증)
- 업무 범위 확장 (새로운 업무 수행)
- 직무 전문성 향상 (역량 모델 기반 레벨업)
```

**조직 역량 축적 (15%)**

```
측정:
- 지식 문서화: 나만 아는 것 → 팀이 아는 것
  (위키 작성, SOP 정리, 케이스 스터디)

- 백업 인력 육성: 내가 없어도 돌아가는 팀
  (후임 교육, 업무 인수인계 체계화)

- 시스템화: 사람 의존 → 시스템 의존
  (자동화, 템플릿, 체크리스트)
```

**지속가능성 (5%)**

```
측정:
- 번아웃 지수: 초과근무, 휴가 미사용 → 감점
- 팀 건강성 기여: Pulse Survey 점수
- 윤리/컴플라이언스: 위반 시 감점
```

## 실전 적용 예시

### Case: 개발팀 김과장

**AS-IS 평가 (1차원)**

```
상급자 목표: "HR 시스템 구축"
→ 완료 (목표 100% 달성) → A등급
```

**TO-BE 평가 (3차원)**

```
1축: 목표 달성 (40%)
  - 상급자 목표 달성: 100% (25점/25점)
  - 전략 목표 기여: DX 자동화 기여 (12점/15점)
  소계: 37/40점

2축: 실행 품질 (30%)
  - 효율성: 마감 90% 준수, 재작업 적음 (8점/10점)
  - 협업: 타팀 기술지원 6건, Notion 문서 15건 (9점/10점)
  - 개선: 배포 자동화로 팀 시간 30% 절감 (10점/10점)
  소계: 27/30점

3축: 미래 기여 (30%)
  - 개인 성장: 새 기술 스택 2개 습득 (8점/10점)
  - 조직 역량: 개발 가이드 문서화, 신입 온보딩 체계화 (13점/15점)
  - 지속가능성: 적정 근무, 윤리 준수 (5점/5점)
  소계: 26/30점

총점: 90/100 → S등급
```

**차이점:**

- 기존: 목표만 달성하면 A
- 개선: 목표 달성 + 방식도 좋고 + 미래도 만들었으니 S
