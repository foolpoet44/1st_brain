## 기본 맥락 확인

**1. 데이터 구성**

- 임원세평이 몇 명분인가? (5명? 20명? 100명?)
- 각 세평은 어떤 형식인가? (자유양식 텍스트? 구조화된 평가지? 혼합?)
- 평가자는 누구인가? (상급자? 동료? 360도?)

**2. 분석의 목적**

- 이 인사이트를 누가 주로 사용할 것인가? (HR팀? 임원진? 리더십 개발팀?)
- 구체적으로 무엇을 알고 싶은가?
  - 임원 집단의 강점/약점 패턴?
  - 개인별 발전 영역?
  - 조직 문화/가치관 정렬도?
  - 리더십 스타일 분포?
  - 역량 갭?

**3. 기존 평가 체계**

- 이미 역량 모델이나 평가 프레임워크가 있는가? (LV, 핵심역량, 행동지표 등)
- AX 전략과의 연계성이 필요한가?

**4. 산출물 형태**

- 임원 보고용 대시보드?
- HR팀의 분석 리포트?
- 개인 피드백 문서?
- 조직 개발 인사이트?

## 360도 텍스트 피드백을 인사이트로 변환하기: 분석 설계

당신이 20명의 임원 360도 평가를 가진 건 조직의 "리더십 건강도"를 진단할 수 있는 기회다. 하지만 원본 텍스트는 그대로 두면 **HR팀의 직관과 편향**, **임원진의 방어기제**에 갇힌다. 이걸 **데이터 기반 인사이트**로 전환하는 게 핵심이야.

### 📊 분석의 철학

세펄 데이터가 아니라 **의미의 층위**를 드러내는 거야. 템플릿을 보니:

- **강점/보완점**: 명시적 피드백
- **조직 평가**: 구성원 관점의 진실
- **행동 사례**: 리더십의 실제 모습

이 셋을 통해:

1. **개인별 360도 프로필** (자신의 강점 vs 조직이 보는 강점의 갭)
2. **조직 수준 리더십 건강도** (8개 역량의 분포, 리스크)
3. **발전 경로** (강점 강화 vs 리스크 완화)

---

## 🔧 분석 파이프라인 설계

### Phase 1: 텍스트 → 구조화 데이터

20명 × 3개 관점(강점/보완점/조직평가) × 자유텍스트 → 8개 역량별 점수 + 정성 요약

**구현 방식:**

- **정량화**: Claude API로 각 텍스트 블록을 8개 역량에 매핑 + 1~10 점수 부여
  - "마이크로매니징" → 권임파워먼트 역량 4/10
  - "기술에 대한 높은 이해도" → 전문성 9/10
  - "감정 표현이 격해질 때" → 자기조절 6/10
- **메타데이터 추출**:
  - 직급, 재직기간, 조직규모
  - 강점-보완점 갭 (조직이 보는 강점 vs 개인 역량의 일관성)
  - 리스크 신호 (조직 평가에서의 우려사항)

### Phase 2: 8개 역량 정의 및 매핑

당신이 리더십 모델이 있다고 했는데, 구체적으로 확인이 필요해. 예를 들어:

- 전략적 사고 / 의사결정
- 인재 육성 / 임파워먼트
- 소통 / 투명성
- 조직관리 / 변화관리
- 협업 / 네트워킹
- 자기개발 / 성찰
- 리스크 관리 / 위기대응
- 성과 창출 / 비즈니스 감각

각 역량별로 **행동 지표**를 설정하면, 텍스트 분석이 더 정확해져.

### Phase 3: 대시보드 설계 (인터랙티브 웹)

**HR팀 관점 (조직관리 역량 + 리스크):**

1. **리더십 프로필 맵** (2축: 현재 역량 vs 기대수준)
   - X축: 전략적 영향도 / Y축: 실행 역량
   - 버블 크기: 조직 규모 (의사결정의 영향도)
   - 색상: 리스크 신호 (초록/노랑/빨강)

2. **역량별 분포 및 갭 분석**
   - 8개 역량별 평균 점수 (20명)
   - 개인별 강점/약점 (히트맵)
   - 직급별 기대 vs 실제 (수평 비교)

3. **리스크 매트릭스**
   - 리더십 리스크: 조직평가 vs 자신의 평가 불일치
   - 조직 효과성 리스크: 마이크로매니징, 소통 부재 등

4. **인재 개발 로드맵**
   - 강점 강화 영역 (이미 9점대, 더 높일 필요 없음)
   - 개선 우선순위 (조직 영향도 높은 역량부터)
   - 개발 프로그램 매칭 (1on1, 리더십 코칭, 파트너십 등)

**임원진 관점 (개인 피드백 + 강점 강화):**

1. **개인별 리더십 프로필**
   - 자신의 강점: "기술 리더십 9/10" → 이 강점이 조직에 미치는 영향
   - 개선 영역: "임파워먼트 4/10" → 왜 필요한가? (경력 성장, 조직 영향도)
   - 360도 피드백: 자신 vs 상급자 vs 동료 vs 부하직원의 평가 차이

2. **강점 강화 전략**
   - 당신의 강점이 **다음 레벨 리더십**에서 어떻게 활용될 수 있는가?
   - "기술 리더십" → "기술 비전 리더십"으로의 진화
   - "성과 창출" → "조직 지속성 창출"로의 확장

3. **액션 플랜**
   - 30/60/90일 마일스톤
   - 코칭 파트너 추천
   - 학습 자료 / 벤치마킹 대상

## 360도 텍스트 분석 → 인사이트 변환: 설계 아키텍처

당신이 원하는 건 **질적 피드백을 정량화하되, 의미를 잃지 않는 것**이다. 이건 단순한 감정 분석이 아니라 **리더십 행동의 패턴 매핑**이다.

### 🧠 분석의 핵심 로직

20명의 임원 × 3개 평가 관점(강점/보완점/조직평가) = 60개의 정성 텍스트 블록. 이걸 **4개 리더십 영역 × 3~4개 지표 = 약 16개 행동 차원**으로 재구성한다.

**예시 (박명주 소장):**

- 원본: "업무 지시는 다소 모호한 반면, 업무 진행 시에는 굉장히 마이크로매니징한다"
- 매핑: `실행 > 임파워먼트` = 4/10 (지시 명확성 낮음, 신뢰 위임 약함)
- 원본: "장비 기술에 대한 높은 이해도와 다년간의 경험을 바탕으로 이슈에 대해 즉각적으로 Idea와 해결책을 제시"

```
  ↓ 지표 04(전략적사고계획) = 6/10
```

**단점**: 맥락 무시, 긍정/부정 감정 반영 필요

## 📚 다른 관점들

### 관점 1: **패턴 분석 (Pattern Recognition)**

세평에서 반복되는 **행동 패턴**을 찾기

```
박명주 세평:
- "마이크로매니징" (여러 번 언급)
- "기술 전문성" (일관되게 강조)
- "소통 부족" (강점에서도, 보완점에서도)

패턴:
기술 전문가 → 세부 통제 → 팀 거리감
```

### 관점 2: **문맥 분석 (Context Analysis)**

**왜** 그렇게 평가했는가의 이유 파악

```
"마이크로매니징을 지적한 이유"
→ 실무자 입장에서 자율이 부족하다는 뜻
→ 조직 차원의 신뢰 부족 신호

"기술 리더십이 9점인 이유"
→ 과제 해결 능력, 선행 개발
→ 하지만 팀원 성장 기회는?
```

### 관점 3: **갭(Gap) 분석 (Contradiction Detection)**

**강점과 보완점의 모순** 찾기

```
박명주:
강점: "구성원을 존중하며, 자율을 부여"
보완점: "마이크로매니징한다는 평이 있음"

갭: 자신의 리더십과 실제 영향의 불일치
인사이트: 자기인식 부족 또는 상황에 따른 불일관성
```

### 관점 4: **스토리텔링 분석 (Narrative Understanding)**

세평의 **흐름**과 **시간성** 이해

```
성대용 세평의 흐름:
1. "처음으로 담당 직책을 맡았을 때" → 새로운 도전
2. "상반기까지 과제 파악" → 적응 과정
3. "지속적으로 자기계발" → 현재 진행형

스토리: 성장 여정, 학습자 마인드셋
인사이트: 초임자의 강점과 개발 기회
```

### 관점 5: **신호 강도 분석 (Signal Strength)**

같은 주제가 **여러 관점에서** 언급되면 신호 강함

```
"소통" 관련 신호:
- 강점: "양방향 소통"이라고 명시
- 보완점: "특정 사안에서 소통이 부족"이라고 지적
- 조직평가: "Vision 전달에 TOP-DOWN 형태"

신호 강도: 높음 → 소통이 진짜 이슈
인사이트: 구조적 소통 개선 필요
```

### 관점 6: **상황적 맥락 (Situational Context)**

**언제, 어디서, 왜** 그런 행동이 나타나는가?

```
박명주:
- 기술 개발 시: 높은 역량
- 팀 관리 시: 마이크로매니징
- 센터장과의 관계: 의존적

상황 맵:
"강점 발휘 조건" vs "약점 드러나는 조건"
```

### 관점 7: **발전 궤적 (Growth Trajectory)**

세평에서 읽을 수 있는 **성장 방향**

```
성대용:
"이 인물에 대한 구성원들의 평가":
→ "상반기까지 신뢰 관계 형성 중"
→ "지속적 자기계발하는 모습"

발전 궤적: 초임 → 안정화 → 리더십 성숙

다음 6개월 포커스: 팀 관리 역량 강화
```

### 관점 8: **조직 신호 (Organizational Signal)**

임원 개인이 아니라 **조직 수준의 신호**

```
박명주 + 성대용 세평 함께 읽으면:

박명주: 마이크로매니징, 소통 부족
성대용: TOP-DOWN 커뮤니케이션

신호: 생산기술원 전체의 리더십 문화가
"통제 중심 → 자율 위임"으로 변화 필요
```

## 🔍 5개 분석 축 (핵심)

### 축1: 핵심 패턴 (Core Pattern)

**"이 임원의 본질이 뭔가?"**

- 반복되는 행동/특성 3-5개
- 예: "기술 전문가마인드", "세부 통제+완벽주의"

### 축2: 갭 분석 (Gap Analysis)

**"강점이라고 한 것이 정말 강점인가?"**

- 강점과 보완점의 모순
- 예: "자율 부여 의도 vs 마이크로매니징 현실"

### 축3: 신호 강도 (Signal Strength)

**"뭐가 진짜 이슈인가?"**

- 여러 관점에서 반복되는 신호 (높음/중간/낮음)
- 예: 소통 (강점+보완점+조직 4곳에서 언급) = 높음

### 축4: 발전 궤적 (Growth Trajectory)

**"이 임원이 어디로 가고 있는가?"**

- 과거 → 현재 → 미래 성장 방향
- 예: Stage 2(초기리더) → Stage 3(성장리더)로 진화 필요

### 축5: 조직 신호 (Organizational Signal)

**"이건 개인 문제가 아니라 조직 문제 아닌가?"**

- 여러 임원에게서 반복되는 테마
- 예: 5명 모두 "소통 부족" → 조직 신호
