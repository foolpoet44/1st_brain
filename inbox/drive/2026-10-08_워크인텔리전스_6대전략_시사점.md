# 6가지 워크 인텔리전스 활용 전략

요약 및 시사점 보고 | 2026. 10. 8. | 생산기술EXG팀

## 1. 핵심 요약

6개 전략은 스킬을 공통 언어로 삼아 직무, 인력, 학습, 시스템을 하나로 엮는 구조로 정리됨.

| 단계 | 전략 | 핵심 내용 |
| :-- | :-- | :-- |
| **기반** | ① 직무 체계 현대화 | 제각각인 내부 직무·스킬을 시장 표준 구조로 통합 |
|  | ② 스킬 프로파일 구축 | 시장 수요 변화에 맞춰 직무별 핵심 스킬을 실시간으로 갱신 |
| **분석** | ③ 전략적 인력 계획 | 새로 떠오르는 스킬 격차를 미리 찾아 미래 인력 수요에 대비 |
|  | ④ AI 영향도 분석 | 태스크 단위로 AI 자동화·증강 기회를 식별하고 직무를 재설계 |
| **실행** | ⑤ 학습 및 리스킬링 | 사업 핵심 스킬과 L&D를 직접 연결해 교육 투자 효율 극대화 |
| **플랫폼** | ⑥ HCM 생태계 활성화 | Workday·SAP 등 기존 HR 시스템 위에 인텔리전스 레이어를 얹음 |

## 2. 시사점

### ① 스킬 체계가 모든 전략의 전제 조건임

- ③~⑥은 모두 ①·②의 표준화된 스킬 데이터가 있어야 작동함.
- 스킬 체계가 없으면 인력 계획, AI 영향 분석, 교육 연계가 각각 따로 굴러가게 됨.

### ② 기준점이 '내부 정의'에서 '시장 표준'으로 이동함

- "시장 친화적", "시장 수요", "시장 맞춤형"이라는 표현이 반복해서 등장함.
- 내부에서 정한 스킬 정의만으로는 외부 채용시장과 비교하거나 Buy/Borrow 판단에 활용하기 어려움.

### ③ 정적인 체계에서 실시간으로 갱신되는 체계로 바뀜

- ②의 '실시간 최신화'와 ③의 '선제적 파악'은 스킬 체계를 한 번 만들고 끝내는 문서가 아니라, 계속 업데이트되는 데이터로 운영해야 한다는 뜻임.

### ④ 분석 단위가 '직무'에서 '태스크'로 내려감

- AI 영향도는 직무 단위로는 판단할 수 없고, 태스크로 쪼개야 자동화(대체)와 증강(보완)을 구분할 수 있음.
- 결국 직무 재설계로 이어지는 흐름임.

### ⑤ 시스템을 교체하지 않고 레이어를 얹는 방식임

- 기존 HCM은 그대로 두고 그 위에 인텔리전스 레이어를 올리는 접근임.
- 대규모 시스템 교체 없이 빠르게 적용할 수 있다는 점이 현실적인 장점임.

## 3. 우리 업무와의 연결

| 전략 | 현재 진행 중인 작업 | 보완 포인트 |
| :-- | :-- | :-- |
| **①②** | 자율공장 스킬 온톨로지, 메타모델 구축 | 외부 시장 스킬 표준과 맞추는 매핑 레이어 검토 |
| **③** | AF 인재 수급 OS, 사업기여형 수급체계, Build/Buy/Borrow | 스킬 격차를 미리 감지하는 지표 설계 |
| **④** | Process-to-Autonomy, 워크플로우 AX 대시보드 | 태스크 단위로 자동화·증강을 분류하는 기준 마련 |
| **⑤** | AI Factory Academy 커리큘럼 | 커리큘럼과 스킬 간 연결 관계로 교육 ROI 측정 |
| **⑥** | HR OS (기존 시스템 위 레이어) | 현행 방향과 일치하므로 보고 시 외부 근거로 활용 가능 |

## 4. 제언

1. **보고 프레임으로 활용:** AF 인재 수급 OS를 설명할 때 이 6단계 구조(기반→분석→실행→플랫폼)에 맞춰 보여주면, 우리 작업이 글로벌 흐름과 같은 방향이라는 점을 바로 보여줄 수 있음.
2. **가장 큰 공백은 외부 연계:** 온톨로지가 사내 정의 중심이라면, 시장 스킬 데이터와 연결하는 부분이 차별화 과제가 될 수 있음.
3. **AI 영향도 분석을 다음 유스케이스로 검토:** 기존 태스크·워크플로우 데이터를 그대로 재활용할 수 있어 빠르게 성과를 낼 수 있는 영역임.
