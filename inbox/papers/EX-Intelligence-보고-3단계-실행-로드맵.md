## 1보고 완료 — "왜 해야 하는가"

조직 건강도 관리의 패러다임 전환 필요성을 설득하고, EX Intelligence 개념과 방향성에 대한 공식 승인을 확보

**1보고의 핵심 논리**

01. **Hidden Risk Zone** — 조직은 갑자기 무너지지 않는다. 신호는 존재하지만 아무도 읽지 못하는 구간이 퇴사와 번아웃에 선행한다.
02. **시간 지체와 해석 실패** — 문제는 데이터 부족이 아니다. 신호가 있어도 너무 늦게, 잘못 읽히는 것이 문제다.

**26%p** 리더–직원 인식 격차 — 리더와 현업 직원의 조직 현실 인식 격차. 출처: Deloitte 2024

CIA — NEED TO KNOW 원칙: "결정이 필요한 사람에게, 필요한 정보를, 필요한 시점에." 데이터 수집 시스템이 아닌 의사결정 지원 시스템이라는 선언

### 1보고 → 2보고: 1보고가 남긴 과제

- **A 설문 문항의 재검토** — 펄스서베이임을 가정하지 말고, 구성원에게 물어야 할 사항의 전체 목록을 먼저 도출할 것
- **B 필요성 인식과 의미 부여** — 왜 체크하는가, 펄스를 안 하면 잃어버리는 것이 무엇인가에 대한 공유된 언어 필요
- **C 결과 활용 체계** — 계층별 점수가 아닌, 조직사기·갈등·협업·리더십 등 현상 카테고리 중심의 리포팅
- **D 카테고리 근거 강화** — 3개(또는 N개) 카테고리의 근거, 측정 항목의 손에 잡히는 구체성

공통된 시사점 — 시스템의 정당성(legitimacy)에 대한 공유된 언어가 아직 없다. 2보고는 이 공백을 채우는 것을 목적으로 한다.

## 2보고 진행 중 — "무엇을 측정할 것인가"

현실 이슈 기반 Full Inventory를 공개하고, 측정방식 분류를 확정하며, 현상 카테고리와 액션 프로토콜 초안을 승인받음

### 2보고 핵심 콘텐츠 1 — 현실 이슈 Full Inventory (8개 클러스터)

| # | 이슈 클러스터 | 현장 헤드라인 | 주요 신호 |
| :-: | :-: | :-: | :-: |
| I01 | 번아웃 & 에너지 고갈 | "사람들이 다 조용히 타고 있다" | 야근 감소에도 지침 / 성과 체감 없음 / 퇴근 후 무력감 |
| I02 | 리더십 신뢰 균열 | "팀장을 믿지 못하겠다" | 공정성 불신 / 피드백 공백 / 형식적 1:1 |
| I03 | AX 변화 불안 & 저항 | "AI가 나를 대체할 것 같아 불안하다" | 역량 공백 / 책임 회피 / 역할 소멸 불안 |
| I04 | 협업 마찰 & 팀 갈등 | "같이 일하기가 너무 힘들다" | 정보 사일로 / 역할 충돌 / 결정 없는 회의 |
| I05 | 심리적 안전감 & 발언 억압 | "말해봤자 다 아무것도 안 바뀐다" | 발언 억압 / 보복 두려움 / 냉소적 침묵 |
| I06 | 성장 단절 & 의미 상실 | "여기서 내가 성장하고 있는지 모르겠다" | 인정 결핍 / 경력 막막함 / 의미 공백 |
| I07 | 조직 방향 불신 & 소속감 약화 | "이 조직이 어디로 가는지 모르겠다" | 전략 불투명 / 소속감 약화 / 이직 의향 |
| I08 | 업무 구조 & 프로세스 기능 장애 | "일하는 방식 자체가 문제다" | 보고 과잉 / 의사결정 병목 / 실행 단절 |

### 2보고 핵심 콘텐츠 2 — 측정방식 매트릭스 (펄스 대상 항목 선별)

- **펄스서베이** — 월 1회 / 5~7문항 (3분 이내). 시간 민감성 높은 신호 포착 — 변화 추세 추적. (I01 번아웃 / I02 리더십 / I03 AX 불안 / I07 이직 신호)
- **심층서베이** — 분기~반기 / 20~30문항. 맥락·원인·구조적 요인 파악. (I04 협업구조 / I06 성장경로 / I08 프로세스 설계)
- **행동·시스템 데이터** — 상시 자동 수집. AI 활용 로그, 회의 참여율, 응답 속도 등 비설문 신호. (I03 AI 통합도 / I08 회의 효율성)
- **대화·정성** — 수시 / 에그짓·1:1·포커스그룹. 해석적 이해 — 수치 뒤의 맥락과 감정. (I05 발언 억압 / I04 갈등 원인)

선별 기준 1: 시간 민감성 — 4주 이내에 의미 있는 변화가 발생하고, 그 변화를 제때 포착하지 못하면 개입 타이밍을 잃는 신호인가

선별 기준 2: 액션 가능성 — 해당 신호가 임계치를 넘었을 때 리더 또는 HR이 즉각 실행할 수 있는 개입 행동이 연결되어 있는가

### 2보고 핵심 콘텐츠 3 — 현상 카테고리 & 액션 프로토콜

| 현상 카테고리 | 포함 클러스터 | 임계치 도달 시 액션 프로토콜 |
| :-: | :-: | :-: |
| 조직 사기 (Morale) | I01 번아웃 / I06 성장 | 해당 팀장에게 케어 알림 발송 → 1:1 주제 가이드 제공 → 2주 후 추적 측정 |
| 갈등 신호 (Tension) | I04 협업 / I05 심리안전 | HR 담당자 직접 팀 방문 인터뷰 → 팀 워크숍 설계 → 4주 후 재측정 |
| 리더십 신뢰 (Leadership) | I02 리더십 | 해당 팀장 코칭 세션 연결 → 리더십 개발 프로그램 우선 배치 → 분기 심층 보완 |
| AX 적응도 (AX Readiness) | I03 AX 불안 | AI 역량 집중 지원 프로그램 배치 → 현장 AX 코치 연결 → 월간 추세 모니터링 |
| 조직 신뢰 (Trust) | I07 방향·소속감 | C레벨 직접 소통 이벤트 설계 → 전략 공유 세션 → 이직 위험군 조기 파악 |

언어 전환의 목적 — 리더가 "우리 팀 점수가 낮다"는 방어적 독해 대신, "현재 협업 마찰 신호가 상승 추세다 — 무엇을 해야 하는가"라는 문제 해결자 모드로 전환되게 한다.

### 2보고 의사결정 포인트

- **펄스 문항 수** — A 5문항(최소 부담, 빠른 응답) / B 7문항(커버리지 우선, 더 많은 신호)
- **카테고리 구조** — A 5개 현상 카테고리(리더 친화적 언어) / B 8개 이슈 클러스터 직접 노출(세분화)
- **액션 프로토콜** — A HR 주도 개입 설계(일관된 품질) / B 리더 자율 가이드 중심(자율성 확보)
- **파일럿 시점** — A 3보고 승인 후 즉시 시작 / B 파일럿 설계 완료 후 시작(완성도 우선)

이 보고에서 확정되어야 하는 승인 사항: ① 8개 현실 이슈 클러스터 확정 ② 펄스 대상 항목 5~7개 선정 ③ 현상 카테고리 구조 승인 ④ 액션 프로토콜 방향성 동의

## 3보고 예정 — 2026.06 — "어떻게 운영할 것인가"

운영 체계 전반을 확정하고, 수요자별 인텔리전스 리포트 목업을 검토하며, 파일럿 범위와 평가 기준을 공식 승인받음

### 3보고 핵심 콘텐츠 1 — 운영 체계 설계 원칙

| 운영 요소 | 설계 원칙 | 구체 방안 |
| :-: | :-: | :-: |
| 측정 주기 | 짧고 빈번하게 — 신호의 연속성 확보 | 월 1회 펄스 (5~7문항, 3분 이내) + 분기 1회 심층 + 상시 행동 데이터 |
| 참여 방식 | 마찰을 줄여 — 응답 행동의 최소화 | Magic Link 방식 (로그인 불필요) / 모바일 최적화 / 업무 시간 중 발송 |
| 동의 체계 | 투명하게 — 참여 전 목적과 활용 방식 공개 | 초기 동의서 제공 + 결과 공개 범위 사전 고지 + 언제든 철회 가능 |
| 익명성 | 안전하게 — 발언의 두려움 제거 | 집계 단위 최소 5인 이상 팀만 노출 / 개인 식별 불가 보장 / 외부 감사 가능 |
| 결과 공유 | 빠르게 — 참여의 의미를 즉각 확인 | 응답 마감 후 2주 이내 결과 공개 + 팀장에게 먼저 브리핑 후 전체 공유 |

지속 가능성의 핵심 — EX Intelligence의 지속 가능성은 참여율에 달려 있다. 참여율은 신뢰에서 나온다. 신뢰는 이 다섯 가지 구조적 보장에서 나온다.

### 3보고 핵심 콘텐츠 2 — 수요자별 인텔리전스 리포트 (세 가지 뷰)

- **리더 뷰 (팀장용)** — 누가 지금 먼저 케어가 필요한가. 팀원별 신호 강도 요약 + 권장 1:1 주제 + 케어 우선순위
- **경영진 뷰 (C레벨용)** — 어느 조직에 자원을 우선 배분해야 하는가. 전사 조직 건강 포트폴리오 + 현상 카테고리별 추세
- **HR 알림 뷰 (담당자용)** — 언제, 어느 강도로 개입해야 하는가. 위험 집단 조기 이상 알림 + 개입 강도 권고 + 히스토리
- **전사 대시보드** — 조직 건강 전체 현황. 현상 카테고리별 신호 지도 + 월간 추세 + 이슈 클러스터 히트맵

"같은 정보를 모두에게 보여주면 아무도 행동하지 못한다. 역할에 따라 해석의 단위와 행동의 단위가 달라져야 한다."

### 3보고 핵심 콘텐츠 3 — 파일럿 계획

- 파일럿 대상: 3~5개 팀 / 100~200명. 현장 · 연구 · 관리 등 다양한 조직 유형 포함
- 파일럿 기간: 8주 (2회 펄스 측정). 1차 측정 → 결과 공유 → 리더 액션 → 2차 측정 → 평가
- 파일럿의 목적: 기술 검증이 아닌 행동 변화 검증 — "이 시스템이 실제 조직의 행동 변화를 만들어내는가"

성공 기준:
① 참여율 70% 이상 — 자발적 참여 기반 신뢰 확인
② 리더 액션 이행률 60% 이상 — 리포트를 받고 실제로 행동했는가
③ "말해도 바뀐다" 체감 10%p 이상 향상 — 심리적 안전감 메타 지표

실패 기준 — 참여율 40% 미만 or 리더 미응답 지속 → 운영 구조 재설계 후 재파일럿

## 타임라인 전체 일정

- **1보고** 2026.03 완료 — 개념 프레임 제안 / CIA 은유 / Hidden Risk Zone / 3수요자 구조 — 방향성 승인
- **2보고 준비** 2026.04~05 — Full Inventory 확정 / 측정방식 매트릭스 / 액션 프로토콜 초안 — 진행 중 ▶
- **2보고** 2026.05 — 8개 클러스터 공개 / 펄스 문항 선별 / 현상 카테고리 승인 — 측정 체계 승인
- **3보고 준비** 2026.05~06 — 운영 프로토타입 / 리포트 목업 / 파일럿 대상 협의 / 시스템 검토 — 예정
- **3보고** 2026.06 — 운영 체계 확정 / 리포트 목업 검토 / 파일럿 계획 승인 / 예산 배정 — 파일럿 개시 승인
- **파일럿** 2026.07~08 — 8주 파일럿 운영 (2회 펄스) / 리더 액션 모니터링 / 중간 점검 — 평가 보고
- **전사 확대** 2026.Q4~ — 파일럿 결과 기반 전사 롤아웃 / 시스템 고도화 / AX maturity 연동 — AX KPI 기여

이 로드맵의 완성 조건 — 팀장 한 명이 "이 리포트 덕분에 팀원과 다른 대화를 했다"고 말하는 순간. 시스템의 가치는 데이터가 아니라 행동에서 증명된다.
