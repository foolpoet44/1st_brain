**Physical AI Tech Leader Pool**

**LV3+ 30명 조직설계 계획서**

작성일: 2026-07-07  |  확보 방식: 내부 육성 100%  |  범위: Pool 구성 (상위 리더십 레이어 제외)

# **1. 목표 및 전제**

Skill Ontology(ESCO 기반 커스터마이징)를 활용해 Physical AI 영역의 사내 인재 30명을 LV3(숙련) 이상으로 육성하는 것이 목표입니다. 외부 채용 없이 100% 내부 인원의 리스킬링으로 확보하며, 이 문서는 Pool 내부의 헤드카운트·구조·시퀀싱·예산만 다룹니다 (Pool을 관장하는 상위 조직/리더십 설계는 범위 밖).

**전제 조건**

  - Skill Ontology는 5단계 숙련도 체계(LV1 입문 ~ LV5 리더/마스터)를 기준으로 함
  - LV3+ = LV3(숙련) + LV4(전문가) + LV5(테크리더) 합산 30명
  - 후보군은 현재 진행 중인 R&D/엔지니어링 조직 내 인원에서 선발 (사업부 무관)
  - 탈락·이탈에 대비해 선발 단계에서 약 20~30% 버퍼를 둠

# **2. 헤드카운트 계획**

**2.1 레벨별 목표 구성 (피라미드 구조)**

| 레벨 | 정의 | 목표 인원 | 비중 |
| :-: | :-: | :-: | :-: |
| LV3 (숙련) | 독립적으로 과제 수행 가능 | 18명 | 60% |
| LV4 (전문가) | 복잡 과제 리드 + 후배 멘토링 | 9명 | 30% |
| LV5 (테크리더) | 온톨로지 거버넌스 + 기술 방향 제시 | 3명 | 10% |
| 합계 |   | 30명 | 100% |

**2.2 기술 트랙별 배분 (5개 트랙 × 평균 6명)**

| 트랙 | LV3 | LV4 | LV5 | 합계 |
| :-: | :-: | :-: | :-: | :-: |
| ① 인지·센싱 (Perception & Sensing) | 4 | 1 | 1 | 6 |

*※ ②, ④ 트랙은 LV5 부재 — 3장 리스크 플래그 참조*

# **3. 조직/멘토링 구조**

Pool 내부는 정식 보고라인이 아닌 '트랙 + 레벨' 매트릭스 구조로 운영합니다. 각 트랙의 LV4/LV5 인원이 자연스럽게 피어 멘토 역할을 겸합니다.

**3.1 텍스트 조직도 (예: 인지·센싱 트랙)**

```
인지·센싱 트랙 (6명)
├─ LV5 테크리더 (1) — 트랙 방향 설정, 온톨로지 검증
│   └─ LV4 전문가 (1) — 심화 프로젝트 리드
│         ├─ LV3 숙련 (2) — 멘티
│         └─ LV3 숙련 (2) — 멘티
```

**3.2 span of control 및 멘토 부하 점검**

| 지표 | 현재 값 | 건강 기준 | 판정 |
| :-: | :-: | :-: | :-: |
| LV5 : LV4 멘토링 비율 | 3 : 9 (1:3) | 1:2~1:4 권장 | 적정 |
| LV4+LV5 : LV3 멘토링 비율 | 12 : 18 (1:1.5) | 1:2~1:3 권장 | 여유 있음 (통합 가능) |
| 트랙당 인원 | 6명 | 5~9명 권장 | 적정 |
| LV5 부재 트랙 수 | 2개 (②, ④) | 0개 권장 | 리스크 |

# **4. 시퀀싱 로드맵 (2026 Q3 ~ 2027 Q2)**

| 시기 | 단계 | 핵심 활동 | 목표 산출물 |
| :-: | :-: | :-: | :-: |
| 2026 Q3(7~9월) | 진단 및 선발 | Skill Ontology 기반 역량 진단, 후보 35~40명 선발(버퍼 포함), 5개 트랙 배정 | 선발 완료 명단, 트랙 배정안 |
| 2026 Q4(10~12월) | LV3 집중 육성 | 트랙별 부트캠프, 실습 프로젝트, 1차 인증 평가 | LV3 이상 30명 달성 (연간 목표) |
| 2027 Q1 | LV3 안정화 + LV4 스트레치 | 상위 12명 대상 심화 프로젝트 리드 부여, 피어 멘토링 시작 | LV4 9명 확정 |
| 2027 Q2 | LV5 후보군 육성 | LV4 중 상위 3~5명 대상 온톨로지 거버넌스·리더십 교육, ②④ 트랙 LV5 공백 보완 | LV5 3명 확정 + 트랙 리스크 해소 |

# **5. 예산 모델링 (육성 투자 기준)**

*신규 채용이 아닌 리스킬링이므로 '급여' 대신 '1인당 육성 투자비용'으로 모델링했습니다. 아래 단가는 계획 수립을 위한 예시치이며, 실제 집행 전 재무팀 표준 단가로 교체가 필요합니다.*

| 항목 | 대상 | 1인당 예시 단가 | 총액 (예시) |
| :-: | :-: | :-: | :-: |
| LV1→LV3 부트캠프 | 30명 | 1,300만원 | 3.9억원 |
| LV3→LV4 심화 과정 | 12명 | 800만원 | 9,600만원 |

| 합계 (멘토링 제외) |   |   | 약 5.06억원 |

*\* 멘토링 기회비용 = 멘토 1인당 주간 멘토링 시간 × 활동 기간 × 사내 로드 인건비 단가. 정확한 산정을 위해 HR/재무팀의 인건비 환산 기준이 필요합니다.*

# **6. 구조적 리스크 및 제언**

  - ① 트랙 내 단일 실패점(SPOF) — 제어·구동(②), HRI(④) 트랙에 LV5가 없어 해당 분야 기술 방향 결정이 특정 LV4 1~2인에게 집중됨. 2027 Q2까지 트랙별 최소 1명의 LV5 확보를 권장.
  - ② 멘토링 여유 대비 트랙 재조정 여지 — LV4+LV5:LV3 비율이 1:1.5로 여유가 있어, 트랙 간 인원 재배치나 소규모 트랙 신설(예: 안전/윤리 전담) 여지가 있음.
  - ③ 100% 내부 육성의 속도 리스크 — 외부 채용 없이 진행하므로 육성 실패·이탈 시 대체 인력 확보가 어려움. 선발 버퍼(35~40명)를 반드시 유지하고, 분기별 중간 평가로 조기 이탈 신호를 포착할 것.
  - ④ LV5 3명 집중 리스크 — 전체 30명 중 LV5가 3명뿐이라 이들의 이탈(퇴사, 타부서 이동) 시 온톨로지 거버넌스 공백 발생 가능. 후속 LV5 후보군(2027 Q2 대상)을 조기에 병행 육성 권장.
