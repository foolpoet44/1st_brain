## 1. 핵심 통찰 (Synthesis)

오늘의 HR Tech 신호들이 가리키는 **단 하나의 방향**은 무엇인가?

> **"AI 는 도구가 아닌, 관계의 재정의다."**

88% 의 조직이 AI 스크리닝을 사용하지만, 71% 는 AI 의 최종 결정에 반대한다. 이는 **기술의 실패**가 아니다. 이는 **신뢰의 구조가 재협상되고 있다**는 신호다.

**과거 (감시자 모델)**:  
AI 는 **자동화된 심판**이다. "AI 가 탈락시켰다 → 탈락." HR 은 AI 의 결정에 **책임을 위임**한다.

**미래 (정원사 모델)**:  
AI 는 **가설 생성기**다. "AI 는 이 스킬 갭을 지적했다. 이 갭은 교육으로 해결 가능한가, 아니면 근본적 부적합인가?" HR 은 AI 의 제안을 **검증의 출발점**으로 삼는다.

## 2. Vault 연결 (Connections)

### 🔗 [[agentic-recruitment-proxy]] → "신뢰 사다리"의 구체화

기존 [[agentic-recruitment-proxy]] 는 "Blind Faith → Distrust → Collaboration"이라는 3 단계 신뢰 사다리를 제시했다. 오늘 브리핑은 이를 **구체적 운영 메커니즘**으로 전환한다:

- **Gate 1 (에이전트 진화 감사)**: 분기별 무작위 10 개 샘플 인간 검증
- **Gate 2 (집중도 한도 심사)**: 특정 대학/기업 출신 30% 초과 시 인간 감사 트리거
- **Gate 3 (신뢰도 점수 도입)**: Medium 이하 신뢰 수준 → 인간 재심사 필수
- **Gate 4 (3 단계 진화 게이트)**: 수정 제안 → A/B 테스트 → 분기별 감사

이 4 개 Human Gate 는 **AI 전자동 금지 구역**을 명시한다.

### 🔗 [[fde-talent-model]] → "정체성 확장"의 채용 언어

스킬 기반 채용이 실패하는 이유는 **정체성 대체** 프레임을 사용하기 때문이다: "당신은 새로운 사람이 되어야 한다." 오늘 신호는 **정체성 확장** 프레임을 요구한다: "당신은 기존 능력을 확장할 수 있다."

**채용 언어 변경 예시**:
- ❌ "이 직무는 5 년 경력의 Python 전문가를 요구합니다" (정체성 대체)
- ✅ "이 직무는 당신의 기존 문제 해결 능력을 Python 으로 확장할 기회를 제공합니다" (정체성 확장)

### 🔗 [[bp-signal-intelligence]] → "신뢰도 vs 타당도"의 경고

100% 신뢰도 (일관된 출력) 가 0% 타당도 (올바른 출력) 를 가질 수 있다. 오늘 Signal 3 은 이를 **후보자 경험**으로 전환한다:

- **Reliability**: AI 가 매번 같은 기준으로 평가한다 (일관성)
- **Validity**: AI 의 평가가 실제 직무 성과와 연결된다 (타당성)

**검증 프로토콜**: AI 평가 리포트에 **신뢰 수준 (High/Medium/Low)** 을 명시하고, Medium 이하일 경우 인간 재심사를 의무화한다.

### 🔗 [[hr-conceptual-atoms]] → "진화 게이트"의 YAML 명세

자기 진화 AI 에이전트를 위한 **Evolution Gate YAML 스키마**를 [[hr-conceptual-atoms]] 에 추가:

```yaml
evolution_gate:
  required: true  # 에이전트 모델 수정 시 인간 승인 필수 여부
  audit_log: true  # 진화 이력 기록 여부
  rollback_enabled: true  # 인간이 롤백할 수 있는 권한 부여 여부
  validation_sample: 10  # 자동 분류/처리 후 무작위 N 개 샘플 인간 검증 (권장: 10)
```

## 3. Human Gate 선언 (Prohibited Zones)

다음 4 개 영역은 **AI 전자동 금지**를 선언한다:

| Gate | 영역 | 인간 심사 요구사항 | 빈도 |
|------|------|-------------------|------|
| #1 | 에이전트 진화 감사 | 무작위 10 개 샘플 평가 검증 | 분기별 |
| #2 | 채용 알고리즘 집중도 | 특정 대학/기업 출신 30% 초과 감사 | 실시간 트리거 |
| #3 | 신뢰도 점수 재심사 | Medium 이하 신뢰 수준 인간 재검토 | 매 평가 |
| #4 | 3 단계 진화 게이트 | 수정 제안, A/B 테스트, 분기별 감사 | 수정 시 + 분기별 |

## 4. 심리학적/철학적 성찰

### 🪞 "신뢰는 위임이 아닌, 협상이다"

전통적 HR 은 **신뢰를 위임**으로 이해했다: "AI 가 잘할 것이니, AI 에게 맡기자." 이는 **신뢰 사다리 1 단계 (Blind Faith)** 다.

오늘의 신호는 **신뢰를 협상**으로 재정의한다: "AI 는 가설을 제시하고, 인간은 맥락을 검증한다." 이는 **신뢰 사다리 3 단계 (Collaboration)** 다.

### 🌱 "정원사는 통제하지 않는다. 관찰한다."

감시자는 **통제**를 추구한다: "AI 가 이 후보자를 탈락시켰다 → 탈락." 이는 **검열**이다. 원본 (후보자의 정체성, 맥락, 잠재력) 을 지운다.

정원사는 **관찰**을 실천한다: "AI 는 이 스킬 갭을 지적했다. 이 갭은 어떤 맥락에서 생성되었는가? 교육으로 해결 가능한가?" 이는 **번역**이다. 원본의 맥락을 보존하면서 실행 가능한 통찰로 전환한다.

> **"번역은 원본을 지우지 않는다. 검열은 지운다."**

HR Tech 의 위험은 AI 를 **검열 도구**로 사용하는 것이다. "이 후보자는 요건을 충족하지 않는다 → 탈락." 이는 원본 (후보자의 고유성) 을 지운다.

HR Tech 의 가능성은 AI 를 **번역 도구**로 사용하는 것이다. "이 후보자는 전통적 요건을 충족하지 않지만, 이 스킬은 우리 조직의 어떤 문제와 연결될 수 있는가?" 이는 원본의 맥락을 보존하면서 **새로운 연결**을 생성한다.
