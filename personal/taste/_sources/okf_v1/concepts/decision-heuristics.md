# Taste Decision Heuristics

이 기준은 **고정 성격표가 아니라 실험할 가설**이다.

| 판단 축 | 선호하는 방향 | 주의할 실패 |
|---|---|---|
| 본질 | 왜 필요한지 분명함 | 표면적 기능·현상 나열 |
| 명료성 | 깊지만 이해하기 쉬움 | 꾸밈과 전문용어가 맥락을 가림 |
| 인간성 | 실제 동기·모순·생활 장면 | 추상적/기계적 일반화 |
| 연결성 | 개념→실행→검증 | 분절된 도구나 단편적 자료 |
| 리듬 | 적절한 여백·짧고 효과적인 반전 | 불필요한 장황함 |
| 자율성 | 사용자의 선택권과 통제 유지 | 에이전트의 불투명한 독단 |

## AI 결과물 평가 질문

1. 내 질문의 본질을 정확히 잡았는가?
2. 충분히 깊으면서도 직관적인가?
3. 사람의 실제 경험과 맥락이 살아 있는가?
4. 실제 실행·수정·검증이 가능한가?
5. 단순 모방이 아닌 나만의 판단과 관점을 반영하는가?

각 질문은 예/아니오가 아닌 1~5점으로 기록할 수 있으나 **가중치는 실증 없이 확정하지 않는다**.

## 예외 규칙

특정 작업에서 사용자가 '숫자만', '비유 없이', '원문 그대로'를 요청하면 이 요청이 일반 취향보다 우선한다.
