# Physical AI / AI Factory Tech Leader 육성

## Compiled Truth

Skill Ontology(ESCO 기반 커스터마이징)를 활용해 **Physical AI 영역 사내 인재 30명을 LV3(Specialist) 이상으로, 외부 채용 없이 100% 내부 리스킬링으로 육성**하는 이니셔티브다. 2026 KPI에 직결되며, [[sf-domain-mapping]]이 밝힌 273명 원석 풀에서 길어 올린다.

**① Pool 조직설계 (30명).** 피라미드 구조 — LV3(숙련) 18명 / LV4(전문가) 9명 / LV5(테크리더) 3명. 5개 기술 트랙(인지·센싱 / 제어·구동 / 시뮬레이션·디지털트윈 / HRI / 시스템통합·안전) × 평균 6명. 정식 보고라인이 아닌 '트랙+레벨' 매트릭스로 LV4/LV5가 피어 멘토를 겸한다. 시퀀싱은 2026 Q3(진단·선발, 버퍼 35~40명) → Q4(LV3 집중, 30명 달성) → 2027 Q1(LV4 9명) → Q2(LV5 3명). 예산 약 5.06억(멘토링 기회비용 별도). **구조적 리스크**: 제어·구동/HRI 트랙에 LV5 부재(SPOF), LV5 3명 집중 이탈 시 온톨로지 거버넌스 공백, 100% 내부 육성의 속도·이탈 리스크 — 선발 버퍼와 분기 중간평가로 완화.

**② 면접 계획서 (Interview Kit).** Tech Leader 포지션 선발용 구조화 면접 — 5원칙(구조화·역량기반·근거기반·3인 패널·정량 스코어카드). 6대 핵심역량(Physical AI 기술 전문성 / Skill Ontology 설계 / 인재 육성·코칭 / 크로스펑셔널 협업 / 문제해결·혁신 / 커뮤니케이션·전파력)을 3인 패널(채용매니저·기술 동료·타부서 협업자)이 분담. 행동·상황·프로브 질문 + 4단계 스코어카드 + 디브리프 템플릿. 이 역량 6종은 [[opq-framework]]의 UCF×Leader Edge 성향 프로파일과 교차 검증 가능한 관측 소스다.

**③ AI Factory 육성체계 v2.2 (커리큘럼).** 4개 칼리지(PA·AA·DT·DI) × 3레벨(Practitioner→Specialist→Expert)의 통합 역량 체계. 159 스킬 온톨로지 · 36과목 · 101학점 · 1,500h + 공통 92h, 5개 특화 트랙(TR201~205)·캡스톤 필수, LV3 Tech Leader 30명 목표. 규모: 피지컬 AI 77스킬(최대) / 에이전틱 34(거버넌스) / 디지털 트윈 22(폐루프 허브) / 데이터 인텔리전스 26(데이터 허브). **이중 폐루프** — 운영 루프(현장→데이터→판단→검증→현장)와 학습 루프(합성 데이터→모델 학습→검증 게이트, 신규 스킬 DTS-023·MVS-023 승인 시 완결). 레벨은 교육 이수가 아니라 **현장 과제 증빙 + 육성위 인증**으로만 완성된다(퍼널: 잠재풀 1,000 → 조기선발 50 → 부트캠프 → 페어·솔로 임베드 → Lv3 30). 도메인 간 크로스 연결이 과목 설계에 공급-소비 관계로 박혀 있다(따로 배워도 함께 일하게 되는 구조). 온톨로지 무변경 원칙 — 신규 8건은 워크벤치 제안→검수→장부 확정 절차 준수.

이 세 문서는 **선발(면접) → 육성(커리큘럼) → 배치(Pool 조직)** 한 사이클을 이룬다. 상위 스킬 온톨로지는 [[escon]](projects/escon)의 College→Level→Enabler→Skill 확장이, 이론적 배경은 [[k-smart-model]]이, 부트캠프 정체성 변환은 [[fde-talent-model]]이 담당한다. 도달 목표 스킬맵과 현재 인재 분포의 좌표계는 [[sf-domain-mapping]]이 제공한다.
