## 📋 실행 계획 (Roadmap)

### Phase 1: manifest.json 하네싱 (1 주)

**목표:** 문서 메타데이터를 실시간으로 추적하는 감시 체계 구축

| 작업                | 설명                                          | 산출물             |
| ------------------- | --------------------------------------------- | ------------------ |
| **스키마 확장**     | `category`, `tags`, `csp_insight` 필드 추가   | `manifest_v2.json` |
| **실시간 감시**     | 새 문서 추가 시 자동 변환 + manifest 업데이트 | `watcher.py`       |
| **역색인**          | 태그/카테고리별 문서 목록 생성                | `index.json`       |
| **변환 파이프라인** | PPTX/XLSX/PDF → MD 배치 처리                  | `convert.py`       |

**체크리스트:**

- [ ] manifest.json 스키마 정의
- [ ] 파일 시스템 감시자 구현 (watchdog)
- [ ] 마크다운 변환기 연동 (existing pipeline)
- [ ] 인덱스 JSON 생성 스크립트

---

### Phase 2: 검색 및 연결 (2 주)

**목표:** 시맨틱 검색과 자동 문서 연결 구현

| 작업             | 설명                                    | 산출물          |
| ---------------- | --------------------------------------- | --------------- |
| **벡터 임베딩**  | 문서 내용을 임베딩 (local LLM 또는 API) | `embeddings/`   |
| **벡터 DB 구축** | Qdrant/LanceDB 에 임베딩 적재           | `vector_store/` |
| **시맨틱 검색**  | 자연어 쿼리 → 관련 문서 반환            | `search.py`     |
| **자동 연결**    | 유사 문서 간 `[[링크]]` 자동 생성       | `linker.py`     |

**체크리스트:**

- [ ] 임베딩 모델 선정 (sentence-transformers 또는 OpenAI)
- [ ] 벡터 DB 설치 및 설정
- [ ] 검색 API 구현 (FastAPI)
- [ ] 유사도 기반 링크 생성 로직

---

### Phase 3: 보고 자동화 (2 주)

**목표:** 과거 보고자료 학습 → 초안 자동 생성

| 작업                | 설명                                     | 산출물           |
| ------------------- | ---------------------------------------- | ---------------- |
| **템플릿 매핑**     | 과거 보고자료에서 패턴 추출 (구조, 문체) | `templates/`     |
| **Claude 연동**     | "이번주 주간보고 만들어줘" → 초안 생성   | `report_gen.py`  |
| **슬라이드 생성**   | 생성된 내용을 PPTX 로 내보내기           | `export_pptx.py` |
| **검수 워크플로우** | 생성된 보고서 검토 → 수정 → 승인         | `review_flow.md` |

**체크리스트:**

- [ ] 과거 보고서 스타일 분석 (프롬프트 엔지니어링)
- [ ] Claude API 연동 스크립트
- [ ] PPTX 템플릿 매핑 (python-pptx)
- [ ] 검수 프로세스 정의

---

### Phase 4: EX Intelligence 대시보드 (3 주)

**목표:** Pulse 신호를 실시간으로 모니터링하는 대시보드 구축

| 작업            | 설명                            | 산출물                |
| --------------- | ------------------------------- | --------------------- |
| **신호 수집**   | Pulse 설문 데이터를 DB 에 적재  | `signals_db/`         |
| **트렌드 감지** | 통계적 이상 감지 (급격한 하락)  | `anomaly_detector.py` |
| **액션 트리거** | 신호 → 추천 액션 (1on1, 인터뷰) | `action_rules.json`   |
| **웹 대시보드** | React 기반 실시간 모니터링 UI   | `dashboard/`          |

**체크리스트:**

- [ ] Pulse 데이터 스키마 정의
- [ ] 이상 감지 알고리즘 구현 (통계적 기준)
- [ ] 액션 루프 정의 (Signal → Action → Track)
- [ ] React 대시보드 개발
