## ⌨ ① Vibe Coding & 개발 생태계

**🟢 `Cursor 3` 등장 — IDE의 종말, Agent 플랫폼의 시작**

어제(4/2) Cursor가 'Glass'라는 코드명으로 개발된 Cursor 3을 공개했다. 자연어 프롬프트로 여러 AI 에이전트를 동시에 구동하는 구조로, 이제 Cursor는 코드 에디터가 아니라 "개발자가 에이전트들을 관리하는 대화 플랫폼"으로 스스로를 재정의했다. CSP 관점에서 이건 단순한 툴 업데이트가 아니다 — HR SaaS를 빌딩할 때 코드를 직접 짜는 시대에서 "에이전트에게 스펙을 전달하는 PM 역할"로 전환이 가속되고 있다는 신호다.

**🟢 `Claude Code vs Cursor` — 2026년 현재 진짜 전략**

2026년 현재 두 도구의 'IDE vs 터미널' 구분은 사실상 무의미해졌다. Claude Code는 VS Code 확장과 브라우저 IDE까지 확장됐고, Cursor도 CLI를 출시했다. 실질적 차이는 "자율성에 얼마나 위임할 것인가"의 철학 문제다. 실무에서 가장 많이 채택되는 패턴은 일상 편집은 Cursor, 대규모 리팩토링·아키텍처 변경은 Claude Code라는 혼합 전략이다. CSP처럼 SW 비전공 Vibe Coder에게 최적 조합은 **claude.ai(설계·대화) + Claude Code(실행·자동화)** — 지금 이 워크플로우가 이미 정답이다.

**🟢 `OpenCode` 126K stars — 오픈소스 생태계의 반란**

MIT 라이선스 기반 OpenCode가 2026년 3월 기준 126K GitHub stars를 달성하며 가장 빠르게 성장하는 AI 코딩 오픈소스 프로젝트가 됐다. 75개 이상의 LLM 프로바이더를 지원하며, 특정 벤더 종속 없이 Claude·GPT·Gemini·Ollama 로컬 모델까지 선택 가능하다. HR SaaS 창업 단계에서 인프라 비용 통제가 중요해지는 시점에, API 키 직접 연결 구조를 미리 이해해두면 유리하다.

2026년 SaaS 애플리케이션은 보다 지능적이고 적응적이며 자율적으로 진화하면서, 전통적인 구독·좌석 기반 라이선스가 사용량 및 성과 기반 하이브리드 과금으로 전환되고 있다. Deloitte는 조직의 절반 이상이 2026년 디지털 전환 예산의 50% 이상을 AI 자동화에 투입할 것으로 예측했다. CSP가 설계할 HR SaaS의 과금 모델을 "좌석 수"가 아닌 "진단 횟수·리포트 건수·Well-Being 개선 지표" 기반으로 설계하는 것이 차별화 포인트가 된다.

**🔴 "Domain-specific Agent가 승자" — HR 버티컬 AI의 블루오션**

2026년 도메인 특화 에이전트가 법무·금융·의료 등 전문 분야에서 범용 AI를 압도하는 승자로 부상할 전망이다. 구매자들은 산업 전문성과 모범 사례를 갖춘 AI 서비스로 몰려들 것이다. "HR 전문가가 만든 HR 에이전트"라는 CSP의 정체성이 바로 이 틈새의 정확한 포지션이다 — 17년 도메인 지식이 가장 강력한 해자다.
