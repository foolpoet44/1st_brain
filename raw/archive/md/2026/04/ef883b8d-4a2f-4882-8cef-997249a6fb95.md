---

현재 이 프로젝트 환경에서는 구글 드라이브에 **직접 파일 업로드**가 불가능한 이유가 있습니다.

**연결된 Google Drive 커넥터**는 파일 검색(Search)과 문서 읽기(Fetch)는 지원하지만, **파일 쓰기(Upload)** 권한은 포함되어 있지 않습니다.

---

대신 **두 가지 대안**을 드릴게요.

**옵션 A — 직접 드래그앤드롭 (가장 빠름)**
이미 다운로드된 `claude_notion_archive_system.html` 파일을 [drive.google.com](https://drive.google.com)에 직접 드래그해서 올리면 됩니다. 30초면 완료됩니다.

**옵션 B — Google Apps Script로 자동 업로드 설정 (한 번 세팅하면 반영구 사용)**

구글 드라이브에 저장하는 Apps Script를 만들어드릴 수 있어요. 이렇게 하면 다음에도 Claude가 생성한 파일을 버튼 클릭 한 번으로 Drive에 저장할 수 있게 됩니다.

어떤 방식으로 진행할까요?

```
This block is not supported on your current device yet.
```

선택을 기다리는 중입니다. 위 옵션 중 하나를 골라주시면 바로 진행할게요.

참고로 각각의 특징을 간단히 정리하면:

- **드래그앤드롭** — 지금 당장 가장 빠름. 별도 설정 없음
- **Apps Script** — 구글 생태계 안에서 반자동화. script.google.com에 한 번 붙여넣기하면 이후 Claude 생성 파일을 버튼 하나로 Drive 저장 가능
- **Drive API 코드** — Python/Node 환경에서 완전 자동화하고 싶을 때. 인증 설정이 필요

**사용법 (3분 소요)**

1. [script.google.com](https://script.google.com) 접속
2. **새 프로젝트** 생성
3. 기존 코드 전체 지우고 → 위 `.gs` 파일 내용 전체 붙여넣기
4. 상단 함수 선택창에서 `uploadHTMLToDrive` 선택
5. **▶ 실행** 클릭 → 권한 허용
6. 완료 팝업에서 Drive 링크 확인

저장 결과: 내 구글 드라이브 → **Claude Artifacts** 폴더 → `claude_notion_archive_system.html`
