## Claude (Message 2)

클로드 스킬(Claude Skills)은 특정 작업을 고품질로 수행하기 위한 모범 사례들을 담은 가이드입니다. 제가 컴퓨터를 사용해 파일을 만들거나 작업할 때 참고하는 전문 지침서라고 생각하시면 됩니다.

## 주요 특징

**파일 형식별 전문성**

- 각 파일 형식(docx, pptx, xlsx, pdf 등)마다 별도의 스킬 파일이 있습니다
- 해당 형식의 문서를 만들 때 최적의 결과를 얻기 위한 세부 지침이 담겨 있습니다

**작업 전 참고**

- 문서나 프레젠테이션을 만들기 전에 관련 스킬 파일을 먼저 읽습니다
- 많은 시행착오를 통해 축적된 노하우가 담겨 있어 처음부터 좋은 결과를 만들 수 있습니다

**스킬의 종류**

1. **공개 스킬** (`/mnt/skills/public/`)
   - docx: Word 문서 작성
   - pptx: PowerPoint 프레젠테이션
   - xlsx: Excel 스프레드시트
   - pdf: PDF 생성 및 편집

2. **사용자 스킬** (`/mnt/skills/user/`)
   - 사용자가 직접 추가한 맞춤형 스킬

예를 들어, "프레젠테이션 만들어줘"라고 요청하시면 저는 먼저 pptx 스킬 파일을 읽어서 슬라이드 레이아웃, 디자인, 내용 구성에 대한 모범 사례를 확인한 후 작업을 시작합니다.

이런 시스템 덕분에 전문적이고 완성도 높은 결과물을 만들 수 있습니다!

## PPTX 스킬 상세 가이드

### 📋 **3가지 주요 작업 방식**

pptx 스킬은 상황에 따라 3가지 다른 접근법을 제시합니다:

---

## 1️⃣ **새 프레젠테이션 만들기 (템플릿 없이)**

### 작업 흐름

HTML로 슬라이드를 디자인한 후 PowerPoint로 변환하는 방식입니다.

**단계별 예시:**

```html
<!-- Step 1: CSS 변수로 디자인 시스템 정의 -->
<style>
  :root {
    --primary-color: #2e86ab;
    --text-color: #333333;
    --heading-font: "Arial", sans-serif;
    --body-font: "Helvetica", sans-serif;
  }
</style>

<!-- Step 2: HTML로 슬라이드 구조 작성 -->
<body style="width: 960px; height: 540px;">
  <div class="row">
    <div class="col">
      <h1>분기별 매출 현황</h1>
      <p>2025년 3분기 실적 보고</p>
    </div>
  </div>
  <div class="placeholder">
    <!-- 차트가 들어갈 자리 -->
  </div>
</body>
```

```javascript
// Step 3: JavaScript로 PowerPoint 생성
const pptxgen = require("pptxgenjs");
const { html2pptx } = require("@ant/html2pptx");

const pptx = new pptxgen();
pptx.layout = "LAYOUT_16x9";

// HTML 슬라이드를 PowerPoint로 변환
const { slide, placeholders } = await html2pptx("slide1.html", pptx);

// placeholder에 차트 추가
slide.addChart(
  pptx.charts.BAR,
  [
    { name: "Q1", labels: ["매출"], values: [120] },
    { name: "Q2", labels: ["매출"], values: [150] },
  ],
  placeholders[0],
);

await pptx.writeFile("output.pptx");
```

**Step 4: 시각적 검증**

```bash
python scripts/thumbnail.py output.pptx workspace/thumbnails --cols 4
```

썸네일을 생성해서 텍스트 잘림, 겹침, 위치 문제 등을 확인합니다.

## 2️⃣ **기존 프레젠테이션 편집하기**

XML 파일을 직접 수정하는 방식입니다.

**실제 작업 예시:**

```bash
# Step 1: 압축 해제
python ooxml/scripts/unpack.py presentation.pptx unpacked/

# Step 2: 파일 구조 확인
unpacked/
├── ppt/
│   ├── slides/
│   │   ├── slide1.xml      # 첫 번째 슬라이드
│   │   ├── slide2.xml      # 두 번째 슬라이드
│   ├── notesSlides/
│   │   └── notesSlide1.xml # 발표자 노트
│   └── presentation.xml     # 메타데이터
```

**slide1.xml 편집 예시:**

```xml
<!-- 제목 텍스트 변경 -->
<a:t>기존 제목</a:t>
↓
<a:t>새로운 제목으로 변경</a:t>
```

```bash
# Step 3: 편집 후 즉시 검증 (매우 중요!)
python ooxml/scripts/validate.py unpacked/ --original presentation.pptx

# Step 4: 다시 압축
python ooxml/scripts/pack.py unpacked/ new_presentation.pptx
```

## 3️⃣ **템플릿 기반으로 새 프레젠테이션 만들기**

기존 템플릿의 디자인을 유지하면서 내용만 바꾸는 방식입니다.

### 실제 워크플로우

**Step 1: 템플릿 분석**

```bash
# 텍스트 추출
python -m markitdown template.pptx > template-content.md

# 시각적 썸네일 생성
python scripts/thumbnail.py template.pptx
```

**Step 2: 템플릿 인벤토리 작성**

```markdown
# Template Inventory Analysis

**Total Slides: 10**
**슬라이드는 0부터 시작 (첫 슬라이드 = 0)**

## 인트로 슬라이드

- Slide 0: Title Slide - 메인 제목, 부제목, 로고
- Slide 1: Section Divider - 섹션 구분용

## 콘텐츠 슬라이드

- Slide 2: Two Column - 왼쪽 텍스트, 오른쪽 이미지
- Slide 3: Bullet Points - 제목 + 3개 불릿
- Slide 4: Chart Layout - 차트용 레이아웃
```

**Step 3: 슬라이드 복제 및 재배열**

```bash
python scripts/clone.py template.pptx working.pptx \
  0,2,2,3,4,1  # 슬라이드 0, 2(2번), 3, 4, 1 순서로 복제
```

**Step 4: 인벤토리 추출**

```bash
python scripts/inventory.py working.pptx > inventory.json
```

**inventory.json 예시:**


## 🎯 **실무 활용 포인트**

### ✅ **언제 어떤 방식을 쓸까?**

- **HTML 방식**: 완전히 새로운 디자인, 복잡한 레이아웃, 차트가 많을 때
- **XML 편집**: 소규모 수정, 특수 기능(애니메이션, 노트) 편집
- **템플릿 방식**: 회사 템플릿 사용, 디자인 일관성 유지 필요

### 📊 **차트 추가 예시**

```javascript
const chartData = [
  {
    name: "실제",
    labels: ["1월", "2월", "3월"],
    values: [10, 20, 15],
  },
  {
    name: "목표",
    labels: ["1월", "2월", "3월"],
    values: [12, 18, 20],
  },
];

slide.addChart(pptx.charts.LINE, chartData, {
  x: 1,
  y: 2,
  w: 8,
  h: 4,
});
```

### 🖼️ **이미지 추가**

```html
<!-- HTML 방식 -->
<div
  style="background-image: url('chart.png'); 
            width: 500px; height: 300px;"
></div>
```

## 🚨 **주의사항**

1. **검증은 필수!** - XML 편집 후에는 항상 `validate.py` 실행
2. **슬라이드는 0부터 시작** - 첫 번째 슬라이드 = slide 0
3. **썸네일로 검토** - 텍스트 잘림, 겹침 등 시각적 문제 확인
4. **템플릿 방식에서 교체하지 않은 shape는 자동으로 비워짐**

# Cursor 웹 버전 정보

## 📱 **현재 상황**

Cursor의 웹 버전은 **완전한 IDE 웹 버전이 아니라**, AI 코딩 에이전트를 브라우저에서 관리할 수 있는 웹 앱입니다.

## 🌐 **Cursor 웹 앱의 기능**

2025년 6월 30일에 출시된 Cursor 웹 앱은 다음 기능을 제공합니다:

### ✅ **할 수 있는 것**

- **백그라운드 에이전트 관리**: 브라우저(데스크톱/모바일)에서 AI 에이전트에게 작업 할당
- **자연어 요청**: 기능 작성이나 버그 수정 같은 코딩 작업 요청
- **진행 상황 모니터링**: 다른 작업 중인 에이전트 확인
- **코드 병합**: 완료된 변경사항을 코드베이스에 통합
- **팀 협업**: 공유 가능한 링크로 팀원의 에이전트 진행 상황 확인

### ❌ **할 수 없는 것**

- **전체 IDE 기능**: 브라우저에서 직접 코드 작성/편집 불가
- **VS Code처럼 사용**: 웹 기반 코드 에디터 역할은 하지 않음

## 💰 **이용 조건**

Cursor 웹 앱은 백그라운드 에이전트 접근 권한이 있는 사용자만 이용 가능하며, Pro 플랜($20/월) 이상 구독자가 사용할 수 있습니다. 무료 티어에서는 사용할 수 없습니다.

## 🔍 **전통적인 웹 IDE는?**

검색 결과에 따르면, Cursor를 웹 서버로 실행하여 브라우저에서 UI에 접근하는 기능에 대한 요청이 있었지만, 이는 아직 공식적으로 지원되지 않습니다.

VS Code처럼 브라우저에서 직접 사용할 수 있는 완전한 웹 IDE 버전은 현재 존재하지 않으며, Cursor는 여전히 **데스크톱 앱 설치가 필요**합니다.

## 🎯 **요약**

- **Cursor 웹 앱**: AI 에이전트 관리용 (2025년 6월 출시)
- **완전한 웹 IDE**: 아직 없음, 데스크톱 앱 필수
- **주요 용도**: 모바일/브라우저에서 코딩 작업 할당 및 모니터링

브라우저에서 직접 코드를 작성하고 싶으시다면, 현재로서는 데스크톱 Cursor 앱을 설치하셔야 합니다!
