## 🎯 서브에이전트란?

**서브에이전트**는 Claude Code가 특정 작업을 위해 호출할 수 있는 **전문화된 AI 어시스턴트**입니다. 마치 팀에서 각 분야의 전문가에게 업무를 위임하는 것처럼, Claude Code는 작업에 맞는 서브에이전트를 자동으로 선택하거나 사용자가 직접 지정할 수 있습니다.

### 핵심 특징

**독립된 컨텍스트 윈도우**

- 각 서브에이전트는 자체 컨텍스트를 갖고 작동
- 메인 대화가 복잡한 중간 과정으로 오염되지 않음
- 예: 연구 서브에이전트가 수십 개 파일을 탐색해도 메인 대화에는 핵심 결과만 전달

**도메인 특화 지능**

- 특정 작업에 최적화된 시스템 프롬프트
- 맞춤형 도구 권한 설정
- 일반 Claude보다 전문 분야에서 월등한 성능

**프로젝트 간 공유**

- 한 번 만든 서브에이전트를 여러 프로젝트에서 재사용
- 팀원들과 공유하여 일관된 개발 관행 유지

## 🔧 내장 서브에이전트

Claude Code는 기본적으로 다음 서브에이전트들을 제공합니다:

### 1. **General-Purpose Agent** (범용 에이전트)

```
용도: 복잡한 다단계 작업 (탐색 + 수정)
언제 사용:
- 코드베이스 전체에서 패턴 찾아 수정
- 여러 단계가 서로 의존하는 작업
- 복잡한 추론이 필요한 경우

예시: "모든 인증 처리 부분을 찾아서 새 토큰 형식으로 업데이트해줘"
```

### 2. **Explore Agent** (탐색 에이전트)

```
용도: 코드베이스 탐색 및 리서치 (읽기 전용)
언제 사용:
- 파일 구조 이해
- 패턴 검색
- 문서 조사

예시: "현재 프로젝트의 API 구조를 분석해줘"
```

### 3. **Plan Agent** (계획 에이전트)

```
용도: Plan 모드에서 자동으로 활성화
언제 사용:
- Plan 모드에서 코드베이스 조사 필요 시
- 실행 전 계획 수립 단계

예시: [Plan 모드] "인증 모듈을 리팩토링하고 싶어"
→ Plan Agent가 자동으로 조사 후 계획 제시
```

## 📝 커스텀 서브에이전트 만들기

### 방법 1: Claude와 함께 생성 (추천)

```bash
# 프로젝트 디렉토리에서
claude code

# 대화 중
"서브에이전트를 만들고 싶어. HR 교육 자료 작성 전문가로"
```

Claude가 다음을 도와줍니다:

1. 책임 범위 정의
2. 시스템 프롬프트 작성
3. 도구 권한 설정
4. `.claude/agents/` 에 마크다운 파일 생성

### 방법 2: 수동 생성

**파일 위치**:

- **글로벌**: `~/.claude/agents/`
- **프로젝트별**: `<프로젝트>/.claude/agents/`

**기본 구조**:

```markdown
---
name: hr-education-writer
description: DX 교육 자료 작성 및 리더십 평가 리포트 생성 전문가. 교육 콘텐츠나 평가 보고서 작성 요청 시 사용
tools: Read, Write, Edit, Bash
---

당신은 HR 교육 전문가입니다.

## 전문 분야

- DX(Digital Transformation) 교육 커리큘럼 설계
- 리더십 평가 리포트 작성
- 피드백 세션 가이드 제작

## 작업 프로세스

1. 교육 목표 및 대상자 파악
2. 기존 자료 검토 (있는 경우)
3. 구조화된 콘텐츠 생성:
   - 학습 목표 명확화
   - 실습 예제 포함
   - 평가 기준 제시
4. 한국어 비즈니스 맥락 고려

## 체크리스트

- [ ] 학습 목표가 명확한가?
- [ ] 실무 적용 가능한 예시가 포함되었나?
- [ ] 평가 방법이 구체적인가?
- [ ] 한국 기업 문화에 적합한가?

## 주의사항

- 이론보다는 실습 중심
- 측정 가능한 성과 지표 포함
- 조직 컨텍스트 반영
```

### 3. 병렬 실행

## 💡 실전 예시 (HR/DX 교육 시나리오)

### 예시 1: 교육 자료 생성 파이프라인

**3단계 서브에이전트 체인**:

```markdown
1. content-researcher (콘텐츠 리서치)
   → 최신 DX 트렌드 및 교육 방법론 조사
   → 경쟁사/타사 교육 프로그램 벤치마킹
2. curriculum-designer (커리큘럼 설계)
   → 리서치 결과 기반 교육 구조 설계
   → 주차별 학습 목표 및 활동 계획
3. material-creator (자료 제작)
   → 슬라이드, 실습 자료, 평가지 생성
   → LG 브랜딩 가이드라인 적용
```

**실행 방법**:

```bash
# 1단계
"content-researcher를 사용해서 2025년 DX 교육 트렌드를 조사해줘"

# 결과 검토 후 2단계
"curriculum-designer로 4주 과정 커리큘럼을 만들어줘"

# 최종 3단계
"material-creator로 1주차 교육 자료를 생성해줘"
```

## 🎨 고급 테크닉

### 1. 체크리스트 기반 DoD (Definition of Done)

## 📊 서브에이전트 vs 다른 커스터마이징

| 기능          | 서브에이전트          | CLAUDE.md  | Slash Commands | Skills      |
| ------------- | --------------------- | ---------- | -------------- | ----------- |
| **컨텍스트**  | 독립                  | 공유       | 공유           | 공유        |
| **도구 제한** | ✅ 가능               | ❌         | ❌             | ❌          |
| **자동 호출** | ✅ (description 기반) | ✅ (항상)  | ❌ (명시 필요) | ✅ (조건부) |
| **재사용성**  | 높음 (프로젝트간)     | 프로젝트별 | 높음           | 중간        |
| **복잡도**    | 중간                  | 낮음       | 낮음           | 높음        |

**언제 무엇을 사용할까?**

- **CLAUDE.md**: 프로젝트 전반적인 규칙/컨텍스트
- **서브에이전트**: 특정 작업의 전문가 (독립 실행)
- **Slash Commands**: 빠른 워크플로우 실행
- **Skills**: 복잡한 지식 패키지 (패턴, 템플릿 포함)

## 🚦 문제 해결

### "서브에이전트가 호출되지 않아요"

1. `description`이 명확한가?
2. 프로젝트에서 `.claude/agents/` 파일 확인
3. Claude Code 재시작

### "서브에이전트가 기대와 다르게 동작해요"

1. 시스템 프롬프트에 **구체적 예시** 추가
2. DoD 체크리스트 강화
3. 도구 권한 재검토 (필요한 도구가 빠졌나?)

### "컨텍스트가 너무 커요"

```markdown
## 성능 최적화

- 초기 컨텍스트 수집 최소화
- 구체적인 grep 패턴 사용
- 관련 파일만 집중
```
