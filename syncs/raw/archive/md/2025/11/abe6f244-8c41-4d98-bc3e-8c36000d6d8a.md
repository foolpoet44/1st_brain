## 📋 Claude Code 프로젝트 관리 시스템

### **1단계: 메인 데이터베이스 생성**

**데이터베이스 이름**: "Claude Code 프로젝트"

**필수 속성 (Properties)**:

1. **프로젝트명** (제목)
   - 타입: Title

2. **상태** (Status)
   - 타입: Select
   - 옵션:
     - 🔵 계획중 (Planning)
     - 🟡 진행중 (In Progress)
     - 🟢 완료 (Completed)
     - 🔴 보류 (On Hold)
     - ⚫ 취소됨 (Cancelled)

3. **우선순위** (Priority)
   - 타입: Select
   - 옵션:
     - 🔥 긴급 (Urgent)
     - ⭐ 높음 (High)
     - 📌 보통 (Medium)
     - 💤 낮음 (Low)

4. **프로젝트 타입** (Project Type)
   - 타입: Multi-select
   - 옵션:
     - 웹 개발
     - API 개발
     - 데이터 분석
     - 자동화 스크립트
     - 버그 수정
     - 리팩토링
     - 새 기능 개발

5. **기술 스택** (Tech Stack)
   - 타입: Multi-select
   - 옵션: Python, JavaScript, React, Node.js, Django, FastAPI, SQL, MongoDB, Docker 등

6. **시작일** (Start Date)
   - 타입: Date

7. **마감일** (Due Date)
   - 타입: Date

8. **진행률** (Progress)
   - 타입: Number
   - Format: Percent

9. **담당자** (Assignee)
   - 타입: Person

10. **Claude Code 세션** (Sessions)
    - 타입: Number
    - 설명: Claude Code를 사용한 세션 수

11. **GitHub 링크** (GitHub URL)
    - 타입: URL

12. **작업 로그** (Work Log)
    - 타입: Relation (하위 데이터베이스와 연결)

---

### **2단계: 작업 로그 데이터베이스 생성**

**데이터베이스 이름**: "Claude Code 작업 로그"

**속성**:

1. **작업명** (제목)
   - 타입: Title

2. **관련 프로젝트** (Related Project)
   - 타입: Relation (메인 프로젝트 DB와 연결)

3. **작업 일자** (Date)
   - 타입: Date

4. **소요 시간** (Duration)
   - 타입: Number (시간 단위)

5. **작업 내용** (Description)
   - 타입: Text

6. **사용한 명령어** (Commands Used)
   - 타입: Text

7. **생성된 파일** (Files Created)
   - 타입: Multi-select

8. **발생한 이슈** (Issues)
   - 타입: Multi-select
   - 옵션: 버그, 성능, 설계 변경, 의존성 충돌 등

9. **해결 방법** (Solution)
   - 타입: Text
