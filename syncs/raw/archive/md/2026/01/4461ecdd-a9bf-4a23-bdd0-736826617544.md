## 경제적 자유의 세 가지 차원

### 1. **시간의 자유** (Time Sovereignty)

"내 시간이 돈으로 환산되지 않는 상태"

- 현재: 시간 = 임금 (노동소득)
- 목표: 시간 ≠ 수입 (자본소득 > 생활비)
- 핵심 지표: **수동소득/월지출 비율**

### 2. **선택의 자유** (Optionality)

"원치 않는 일을 거절할 수 있는 능력"

- 창업 실패 시에도 생활 가능한 버퍼
- 기회비용을 감당할 수 있는 여유
- 핵심 지표: **비상자금 (생활비 × 24개월)**

### 3. **실험의 자유** (Creative Capital)

"실패해도 괜찮은 자본"

- SaaS 개발/마케팅 투자금
- 신기술 학습 비용
- 핵심 지표: **창업 준비 자금 (사업계획 × 1.5배)**

- HR 전문가로서 당신은 "시간 → 임금"의 선형 교환을 해왔습니다.

**핵심 통찰**:
돈이 일하게 만드는 것은 "투자 수익률"의 문제가 아니라,
**"나의 시간과 에너지를 최고 가치 활동에 집중할 수 있는 구조"**를 만드는 것입니다.

## 전략의 철학적 기반

CSP님, 투자 전략을 짜기 전에 먼저 **당신이 어떤 투자자인지** 정의해야 합니다.

그렇다면 당신의 투자 전략은 다음 원칙을 따라야 합니다:

**원칙 4: 실패는 옵션이 아니다** → 창업자금 손실 방지가 최우선

이것은 "수익률 극대화" 게임이 아니라 **"목표 달성 확률 극대화"** 게임입니다.

## 채권 투자: 당신의 비밀 무기

CSP님, 당신은 채권에 관심이 많다고 하셨죠? 이것이 당신의 강점이 될 수 있습니다.

**왜 채권인가?**

대부분의 개인 투자자는 채권을 무시합니다. "재미없고", "수익률 낮고", "복잡하다"고 생각하죠. 하지만 채권은 **예측 가능성**이 가장 높은 자산입니다.

주식은 기업 실적, 시장 심리, 예상치 못한 뉴스에 흔들립니다. 하지만 채권은 금리와 신용등급만 보면 됩니다. 그리고 당신은 분석 역량이 있습니다.

**한국 국고채 투자 전략:**

한국은행 기준금리 사이클을 읽으세요. 2024년 말 기준으로 한국은행은 금리 인하 사이클에 있을 가능성이 큽니다. (물론 2026년 2월 현재 상황은 웹 검색으로 확인 필요)

**금리 인하기에는 장기채가 유리합니다.** 왜냐하면:

1. 금리 하락 → 채권 가격 상승 → 시세차익
2. 높은 쿠폰 수익률 고정

예를 들어 지금 3년물 국고채를 3.5%에 샀는데, 1년 후 금리가 2.5%로 떨어지면 당신의 채권 가격은 올라갑니다. 만기까지 보유해도 3.5% 확정이지만, 중간에 팔면 추가 수익도 가능합니다.

**실전 팁:**

- 증권사 HTS/MTS에서 "국고채 시장"으로 가세요
- 3년물, 5년물 수익률 곡선을 봅니다
- 역사적 평균 대비 지금 매력적인지 판단
- 한국은행 통화정책회의 의사록 읽기 (2개월마다)

이것은 투자이자 **거시경제 공부**입니다. 창업가는 경제 흐름을 읽을 줄 알아야 합니다.

| **자산 유형**       | Select   | 국내주식ETF, 해외주식ETF, 국내채권, 해외채권, 개별주, 현금 |
| **자산군**          | Select   | 성장자산, 안정자산, 현금성                                 |
| **티커/종목코드**   | Text     | 379800, SHY 등                                             |
| **매수 평균가**     | Number   | Rollup from Transactions                                   |
| **현재가**          | Number   | 수동 입력 (주 1회)                                         |
| **보유 수량**       | Number   | Rollup from Transactions                                   |
| **평가금액**        | Formula  | 현재가 × 보유수량                                          |
| **매수금액**        | Formula  | 매수평균가 × 보유수량                                      |
| **수익률 (%)**      | Formula  | (평가금액 - 매수금액) / 매수금액 × 100                     |
| **수익금액**        | Formula  | 평가금액 - 매수금액                                        |
| **목표 비중 (%)**   | Number   | Phase별로 다름                                             |
| **현재 비중 (%)**   | Formula  | 평가금액 / 총자산 × 100                                    |
| **리밸런싱 필요**   | Formula  | if(abs(현재비중 - 목표비중) > 5, "🔄", "")                 |
| **관련 거래**       | Relation | → Transactions                                             |
| **마지막 업데이트** | Date     | 자동                                                       |

**핵심 포인트:**

- 모든 계산은 자동화 (Formula/Rollup)
- 목표 비중 대비 현재 비중 자동 비교
- 리밸런싱 신호 자동 표시

### 자동화 1: 주가/채권 가격 자동 업데이트

**방법:**

- Python 스크립트 (주 1회 실행)

**의사 코드:**

```python
# 매주 일요일 밤 자동 실행 (Cron)
import requests

# 1. Notion에서 보유 종목 리스트 가져오기
holdings = notion_api.get_database("Portfolio Holdings")

# 2. 각 종목 현재가 크롤링
for asset in holdings:
    ticker = asset['ticker']
    current_price = get_price_from_naver(ticker)  # 네이버 금융 크롤링

    # 3. Notion 업데이트
    notion_api.update_page(asset['id'], {
        "현재가": current_price,
        "마지막 업데이트": today
    })

# 4. Slack 알림: "포트폴리오 가격 업데이트 완료"
```

**효과:** 매주 일요일 밤에 자동으로 모든 자산 가격 업데이트 → 월요일 아침 대시보드 보면 최신 상태

## 🎯 철학적 기반: 왜 Market Intelligence인가?

### 문제 인식

투자에서 가장 큰 실수는 **"그때 왜 그랬지?"**를 모르는 것입니다.

- 6개월 전에 왜 국고채를 샀는지 기억 안 남
- 주식 팔았는데 근거가 뭐였는지 망각
- 같은 실수를 반복 (공포에 팔고, 탐욕에 사고)

### 해결 철학

**"Thinking in Writing"** - 생각을 글로 쓰면 명확해집니다.

CSP님은 심리학 백그라운드가 있으시니 아시겠지만:

- **외현화(Externalization)**: 머릿속 생각 → 글 → 객관적 검토 가능
- **메타인지(Metacognition)**: 내 사고 과정을 관찰 → 패턴 발견 → 개선
- **경험 학습(Experiential Learning)**: 기록 → 실행 → 결과 → 복기 → 내재화

Market Intelligence는 단순 뉴스 스크랩이 아니라 **"투자 사고의 진화 과정"**을 추적하는 도구입니다.

- 재현 가능 (언제든 재생성)

## 💻 핵심 코드 구현

### 1. Notion Client 래퍼

**utils/notion_client.py:**

```python
"""
Notion API Client Wrapper
간단하고 재사용 가능한 Notion API 래퍼
"""

from notion_client import Client
from typing import Dict, List, Optional
import os
from dotenv import load_dotenv

# 환경변수 로드
load_dotenv()


class NotionClient:
    """
    Notion API를 쉽게 사용하기 위한 래퍼 클래스

    철학:
    - 복잡한 Notion API를 단순화
    - 에러 핸들링 자동화
    - 재사용 가능한 메서드 제공
    """

    def __init__(self):
        """Notion Client 초기화"""
        self.token = os.getenv("NOTION_TOKEN")
        if not self.token:
            raise ValueError("NOTION_TOKEN이 .env에 설정되지 않았습니다.")

        self.client = Client(auth=self.token)
        self.parent_page_id = os.getenv("PARENT_PAGE_ID")

    def create_database(
        self,
        title: str,
        properties: Dict,
        parent_page_id: Optional[str] = None
    ) -> Dict:
        """
        Notion Database 생성

        Args:
            title: Database 제목
            properties: 필드 정의 (스키마)
            parent_page_id: 부모 페이지 ID (선택)

        Returns:
            생성된 Database 정보
        """
        parent_id = parent_page_id or self.parent_page_id

        try:
            response = self.client.databases.create(
                parent={
                    "type": "page_id",
                    "page_id": parent_id
                },
                title=[
                    {
                        "type": "text",
                        "text": {"content": title}
                    }
                ],
                properties=properties
            )

            print(f"✅ Database '{title}' 생성 완료!")
            print(f"   ID: {response['id']}")
            return response

        except Exception as e:
            print(f"❌ Database 생성 실패: {e}")
            raise

    def update_database_properties(
        self,
        database_id: str,
        properties: Dict
    ) -> Dict:
        """
        Database 속성(필드) 업데이트

        Args:
            database_id: Database ID
            properties: 추가/수정할 필드

        Returns:
            업데이트된 Database 정보
        """
        try:
            response = self.client.databases.update(
                database_id=database_id,
                properties=properties
            )

            print(f"✅ Database 속성 업데이트 완료!")
            return response

        except Exception as e:
            print(f"❌ 속성 업데이트 실패: {e}")
            raise

    def create_page(
        self,
        database_id: str,
        properties: Dict,
        children: Optional[List] = None
    ) -> Dict:
        """
        Database에 새 페이지 생성

        Args:
            database_id: Database ID
            properties: 페이지 속성 (필드 값)
            children: 페이지 내용 블록 (선택)

        Returns:
            생성된 페이지 정보
        """
        payload = {
            "parent": {"database_id": database_id},
            "properties": properties
        }

        if children:
            payload["children"] = children

        try:
            response = self.client.pages.create(**payload)
            print(f"✅ 페이지 생성 완료!")
            return response

        except Exception as e:
            print(f"❌ 페이지 생성 실패: {e}")
            raise

    def query_database(
        self,
        database_id: str,
        filter_obj: Optional[Dict] = None,
        sorts: Optional[List] = None
    ) -> List[Dict]:
        """
        Database 쿼리 (검색)

        Args:
            database_id: Database ID
            filter_obj: 필터 조건
            sorts: 정렬 조건

        Returns:
            검색된 페이지 리스트
        """
        payload = {"database_id": database_id}

        if filter_obj:
            payload["filter"] = filter_obj
        if sorts:
            payload["sorts"] = sorts

        try:
            response = self.client.databases.query(**payload)
            return response["results"]

        except Exception as e:
            print(f"❌ Database 쿼리 실패: {e}")
            raise
```

```python
from config.notion_schema import MARKET_NOTES_PROPERTIES


def create_market_notes_database():
    """
    Market Notes Database 생성
    """
    print("=" * 60)
    print("🚀 Market Notes Database 생성 시작")
    print("=" * 60)

    # Database 생성
    db_response = notion.create_database(
        title="📝 Market Notes",
        properties=MARKET_NOTES_PROPERTIES
    )

    database_id = db_response["id"]

    # .env 파일에 DB ID 저장
    env_path = ".env"

    # 기존 .env 읽기
    with open(env_path, "r", encoding="utf-8") as f:

    with open(env_path, "w", encoding="utf-8") as f:
        f.writelines(lines)

    print("\n" + "=" * 60)
    print("✅ 완료!")
    print(f"   Database ID: {database_id}")
    print(f"   .env 파일에 저장됨")

    return database_id
```

```python
"""
주가/채권 가격 자동 업데이트

스케줄:
- 매주 일요일 밤 자동 실행 (Cron)
- 또는 수동 실행

역할:
- Portfolio Holdings의 "현재가" 필드 업데이트
- 네이버 금융 또는 증권사 API에서 가격 크롤링
"""

import sys
import os

sys.path.append(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from utils.notion_client import notion
from dotenv import load_dotenv
import requests
from bs4 import BeautifulSoup

load_dotenv()


def get_stock_price(ticker: str) -> float:
    """
    네이버 금융에서 주가 가져오기

    Args:
        ticker: 종목코드 (예: 379800)

    Returns:
        현재가
    """
    url = f"https://finance.naver.com/item/main.nhn?code={ticker}"

    try:
        response = requests.get(url)
        soup = BeautifulSoup(response.text, 'html.parser')

        # 현재가 파싱
        price_element = soup.select_one('.no_today .blind')
        if price_element:
            price = price_element.text.replace(',', '')
            return float(price)

        return None

    except Exception as e:
        print(f"❌ 가격 가져오기 실패 ({ticker}): {e}")
        return None


def update_portfolio_prices():
    """
    Portfolio Holdings의 모든 자산 가격 업데이트
    """
    portfolio_db_id = os.getenv("PORTFOLIO_DB_ID")

    if not portfolio_db_id:
        print("❌ PORTFOLIO_DB_ID가 설정되지 않았습니다.")
        return

    print("=" * 60)
    print("📊 Portfolio 가격 업데이트 시작")
    print("=" * 60)

    # Portfolio Holdings 쿼리
    holdings = notion.query_database(portfolio_db_id)

    for holding in holdings:
        # 티커 가져오기
        ticker_prop = holding["properties"].get("티커/종목코드")
        if not ticker_prop or not ticker_prop.get("rich_text"):
            continue

        ticker = ticker_prop["rich_text"][0]["plain_text"]

        # 가격 가져오기
        print(f"\n{ticker} 가격 조회 중...")
        price = get_stock_price(ticker)

        if price:
            # Notion 업데이트
            notion.client.pages.update(
                page_id=holding["id"],
                properties={
                    "현재가": {"number": price}
                }
            )
            print(f"✅ 업데이트 완료: ₩{price:,.0f}")
        else:
            print(f"⚠️ 가격 조회 실패")

    print("\n" + "=" * 60)
    print("✅ 가격 업데이트 완료!")
    print("=" * 60)


if __name__ == "__main__":
    update_portfolio_prices()
```

```python
"""
Market Notes Database 초기 설정
- DB 생성
- 스키마 적용
- 검증
"""

import os
from notion_client import Client
from dotenv import load_dotenv
from config.notion_schema import MARKET_NOTES_PROPERTIES

load_dotenv()


def setup_database():
    """DB 생성 및 설정"""
    client = Client(auth=os.getenv("NOTION_TOKEN"))
    parent_page_id = os.getenv("PARENT_PAGE_ID")

    print("🚀 Market Notes DB 생성 중...")

    try:
        # Database 생성
        response = client.databases.create(
            parent={"type": "page_id", "page_id": parent_page_id},
            title=[{"type": "text", "text": {"content": "📝 Market Notes"}}],
            properties=MARKET_NOTES_PROPERTIES
        )

        db_id = response["id"]
        print(f"✅ 생성 완료! DB ID: {db_id}")

        # 환경변수 출력 (GitHub Secrets에 추가용)
        print("\n" + "=" * 60)
        print("📝 다음 값을 GitHub Secrets에 추가하세요:")
        print(f"   MARKET_NOTES_DB_ID={db_id}")
        print("=" * 60)

        return db_id

    except Exception as e:
        print(f"❌ 실패: {e}")
        raise


if __name__ == "__main__":
    setup_database()
```

```python
"""
시스템 헬스체크
- DB 연결 확인
- 최근 데이터 확인
- 통계 출력
"""

import os
from notion_client import Client
from dotenv import load_dotenv
from datetime import datetime, timedelta

load_dotenv()


def health_check():
    """시스템 상태 체크"""
    client = Client(auth=os.getenv("NOTION_TOKEN"))
    db_id = os.getenv("MARKET_NOTES_DB_ID")

    print("=" * 60)
    print("🏥 Market Intelligence Health Check")
    print(f"   Time: {datetime.now().isoformat()}")
    print("=" * 60)

    try:
        # 1. DB 연결 확인
        print("\n1️⃣ Database Connection...")
        db = client.databases.retrieve(database_id=db_id)
        print(f"   ✅ Connected: {db['title'][0]['plain_text']}")

        # 2. 전체 페이지 수
        print("\n2️⃣ Total Pages...")
        all_pages = client.databases.query(database_id=db_id)
        total = len(all_pages["results"])
        print(f"   ✅ Total notes: {total}")

        # 3. 최근 7일 생성된 페이지
        print("\n3️⃣ Recent Activity (7 days)...")
        seven_days_ago = (datetime.now() - timedelta(days=7)).isoformat()

        recent_pages = client.databases.query(
            database_id=db_id,
            filter={
                "property": "작성일",
                "date": {
                    "on_or_after": seven_days_ago
                }
            }
        )
        recent_count = len(recent_pages["results"])
        print(f"   ✅ Recent notes: {recent_count}")

        # 4. 카테고리별 통계
        print("\n4️⃣ Category Distribution...")
        categories = {}
        for page in all_pages["results"]:
            cat_prop = page["properties"].get("카테고리", {})
            if cat_prop.get("select"):
                cat = cat_prop["select"]["name"]
                categories[cat] = categories.get(cat, 0) + 1

        for cat, count in sorted(categories.items(), key=lambda x: x[1], reverse=True):
            print(f"   • {cat}: {count}")

        print("\n" + "=" * 60)
        print("✅ Health check passed!")
        print("=" * 60)

        return True

    except Exception as e:
        print(f"\n❌ Health check failed: {e}")
        raise


if __name__ == "__main__":
    health_check()
```

```python
"""
Market Notes 백업
- 전체 DB 데이터를 JSON으로 추출
- GitHub Artifacts에 저장
"""

import os
import json
from notion_client import Client
from dotenv import load_dotenv
from datetime import datetime

load_dotenv()


def backup_database():
    """DB 백업"""
    client = Client(auth=os.getenv("NOTION_TOKEN"))
    db_id = os.getenv("MARKET_NOTES_DB_ID")

    print("💾 Backing up Market Notes...")

    # 전체 페이지 조회
    all_pages = []
    has_more = True
    start_cursor = None

    while has_more:
        response = client.databases.query(
            database_id=db_id,
            start_cursor=start_cursor
        )
        all_pages.extend(response["results"])
        has_more = response["has_more"]
        start_cursor = response.get("next_cursor")

    # 백업 파일 생성
    os.makedirs("backups", exist_ok=True)

    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"backups/market_notes_{timestamp}.json"

    backup_data = {
        "backup_time": datetime.now().isoformat(),
        "total_pages": len(all_pages),
        "database_id": db_id,
        "pages": all_pages
    }

    with open(filename, "w", encoding="utf-8") as f:
        json.dump(backup_data, f, ensure_ascii=False, indent=2)

    print(f"✅ Backup saved: {filename}")
    print(f"   Total pages: {len(all_pages)}")

    return filename


if __name__ == "__main__":
    backup_database()
```

```python
"""
거래 내역 자동 추가
GitHub Actions에서 수동 트리거
"""

import argparse
import os
from notion_client import Client
from datetime import datetime
from dotenv import load_dotenv

load_dotenv()


def add_transaction(asset: str, trans_type: str, amount: float, quantity: float, reason: str = ""):
    """거래 추가"""
    client = Client(auth=os.getenv("NOTION_TOKEN"))
    db_id = os.getenv("TRANSACTIONS_DB_ID")

    # 페이지 속성 구성
    properties = {
        "거래일": {
            "date": {"start": datetime.now().date().isoformat()}
        },
        "자산": {
            "title": [{"text": {"content": asset}}]
        },
        "거래 유형": {
            "select": {"name": trans_type}
        },
        "수량": {
            "number": quantity
        },
        "거래금액": {
            "number": amount
        },
        "거래 근거": {
            "rich_text": [{"text": {"content": reason or "수동 입력"}}]
        },
        "감정 상태": {
            "select": {"name": "😌 냉정"}
        }
    }

    # 페이지 생성
    client.pages.create(
        parent={"database_id": db_id},
        properties=properties
    )

    print(f"✅ Transaction added: {asset} - {trans_type} - ₩{amount:,.0f}")


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--asset", required=True)
    parser.add_argument("--type", required=True)
    parser.add_argument("--amount", type=float, required=True)
    parser.add_argument("--quantity", type=float, required=True)
    parser.add_argument("--reason", default="")

    args = parser.parse_args()

    add_transaction(
        asset=args.asset,
        trans_type=args.type,
        amount=args.amount,
        quantity=args.quantity,
        reason=args.reason
```

```python
import logging

def setup_logger(name):
    """로거 설정"""
    logger = logging.getLogger(name)
    logger.setLevel(logging.INFO)

    # 파일 핸들러

    )
    fh.setFormatter(formatter)

    logger.addHandler(fh)
    return logger
```
