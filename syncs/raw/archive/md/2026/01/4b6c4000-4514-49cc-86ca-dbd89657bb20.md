### 4️⃣ **컨텍스트 기반 스마트 추천 (Context-Aware Recommender)**

**언제 작동**: 사용자가 "뭐 읽을까?", "추천해줘" 또는 일정 시간대에 자동

**추천 로직**:

```python
if 현재시간 == "평일 아침":
    if 이번주_코딩_학습 < 2:
        return "💻 Dev.to나 CSS-Tricks 추천 (코딩 부족)"
    else:
        return "다른 영역도 고려해보세요"

elif 현재시간 == "점심":
    부족한_영역 = min(HR횟수, Psychology횟수)
    if 부족한_영역 == HR:
        return "👥 HBR 또는 First Round Review"
    else:
        return "🧠 Behavioral Scientist 또는 BPS"

elif 요일 == "주말":
    if 이번주_심층학습 == False:
        return "📚 북마크한 글 중에서 선택:\n [저장된 북마크 리스트]"
```

**개인화 요소**:

- 최근 관심사 (대화에서 자주 언급된 주제)
- 업무 스케줄 (캘린더 연동 시)
- 과거 선호도 (잘 읽은 채널)
