## 공통 업무 워크플로우 재설계 — 대상과 AI Agent 적용 방향

### 왜 '공통 업무'부터인가

기존 대화에서 반복적으로 등장했던 핵심 통찰이 있습니다. PwC가 명시했듯 "기술은 20%이고, 업무 재설계가 80%의 가치를 만든다"는 것. AI를 도입하기 전에 먼저 "이 일은 왜 존재하는가"를 묻는 존재론적 재설계가 전제되어야 합니다. 공통 업무를 우선 대상으로 삼는 이유는 명확합니다. 조직 전체에 반복적으로 발생하고, 시간 소모가 크고, 성과와의 연결이 약하며, 가장 먼저 "이게 정말 사람이 해야 하는 일인가"라는 질문을 던질 수 있는 영역이기 때문입니다.

---

### 재설계 대상 업무 — 3개 우선순위 군

**군 A. 정보 수집·정리·배포형 업무** — 즉시 자동화 가능 영역

이 군은 가장 빠른 ROI를 보여줍니다. 회의록 작성, 주간 업무 보고 취합, 설문 결과 요약, 교육 이수 현황 집계, 채용 공고 초안 생성이 여기에 속합니다. 공통 특징은 "정해진 형식으로 정보를 모아서 다른 누군가에게 전달"하는 구조라는 점입니다. 판단이 거의 없고, 시간이 많이 들며, 결과물의 품질 편차가 큽니다. MS Copilot이 Teams·Outlook·Excel 레이어에서 이 군을 처리하는 1차 진입로가 됩니다.

**군 B. 판단 보조·분석형 업무** — AI 증강(Augmentation) 영역

이 군은 단순 자동화가 아니라 인간의 판단 품질을 AI가 끌어올리는 방식으로 재설계됩니다. 역량 진단 결과 해석, 인터뷰 질문 생성, 교육 대상자 우선순위화, 이탈 위험 신호 감지, 성과 면담 대화 시나리오 설계가 여기에 해당합니다. AntiGravity의 Manager View 방식 — 사람이 방향을 정하고, AI Agent가 병렬로 조사·분석·초안 작업을 수행 — 이 이 군에 가장 잘 맞습니다.

**군 C. 산출물 생성·패키징형 업무** — Vibe-Coding 자동화 영역

보고서 PPT 생성, 교육 자료 초안, AX 성숙도 리포트, Pulse Check 결과 요약 대시보드처럼 최종 산출물을 만들어내는 업무입니다. Lovable로 만든 미니앱이나 Claude Code 기반 Agent가 이 군의 반복 패키징 작업을 대체합니다. CSP가 이미 EX Intelligence 리포트를 HTML로 자동 생성하는 방향으로 탐구해온 것이 이 군의 전형적인 사례입니다.

---

### AI Agent 적용 방향 — 3층 레이어 모델

기존 대화에서 이미 설계했던 3층 레이어를 워크플로우 재설계에 직접 연결하면 다음과 같습니다.

**Layer 1 — 침투 (MS Copilot)**: 도구를 바꾸지 않고 사용 방식만 전환합니다. 이미 쓰고 있는 Teams·Excel·Outlook 안에서 AI가 작동하기 시작하는 레이어입니다. 저항이 가장 낮고, 전사 범위로 가장 빠르게 확산 가능합니다.

**Layer 2 — 심화 (AntiGravity + Lovable)**: 사용자에서 설계자로 전환하는 레이어입니다. "내 업무의 어느 부분이 나여야 하는지"를 다시 정의하는 10주 스프린트가 이 레이어의 핵심 운영 방식입니다. 비개발자도 GUI 기반으로 Agent에게 지시하고, 미니앱을 직접 만들어보는 경험이 심리적 임계점을 넘게 합니다.

**Layer 3 — 내재화 (Claude Code 기반 Custom Agent)**: 개인 자동화가 팀 공유 자산으로 전환되는 레이어입니다. 공통 프롬프트 템플릿, 팀 Agent 라이브러리, AX 쇼케이스를 통해 개인의 성공 사례가 조직 문화로 확산됩니다.

---

### 10주 워크플로우 재설계 스프린트 — 실행 단위

기존 대화에서 설계된 스프린트를 EXG 업무 맥락으로 구체화하면 이렇게 됩니다.

**W1-2 해부**: 본인 업무 중 반복성이 높고 시간 소모가 큰 업무 1개를 선택합니다. 실제 소요 시간을 측정하고 As-Is 흐름을 그립니다. "이 일은 왜 존재하는가"라는 질문을 먼저 던집니다.

**W3-4 실험**: 선택한 업무의 일부를 AI에게 처음으로 위임합니다. 어디서 수정이 필요한지, 어떤 판단은 여전히 사람이 해야 하는지 패턴을 발견합니다.

**W5-6 정제**: 프롬프트를 구체화하고 반복 가능한 형태로 만듭니다. Before/After 시간을 측정합니다.

**W7-8 확장**: 인접한 업무로 적용 범위를 넓힙니다. Layer 2 도구(AntiGravity·Lovable)를 활용해 미니앱이나 자동화 플로우를 직접 만들어봅니다.

**W9-10 공유**: 결과를 문서화하고 AX 쇼케이스에서 발표합니다. "저역량 구성원이 AI 혜택을 가장 많이 받는다"는 연구 결과처럼, 이 발표가 주변 동료의 참여를 촉발하는 행동 전염 효과를 만들어냅니다.

### 성과 측정 — 생산성 10% 검증의 실제

가장 현실적인 측정 방식은 스프린트 참여자가 Before/After 소요 시간을 직접 기록하는 방식입니다. 10주 전후로 대상 업무에 쓰는 시간이 얼마나 줄었는지를 개인 단위로 집계하고, 이를 전사 AX 성숙도 Survey와 교차 분석하면 "생산성 10% 개선"이라는 KPI를 숫자로 가시화할 수 있습니다.

중요한 것은 절대적인 시간 절감보다 "절약된 시간이 어디로 갔는가"입니다. 회수된 시간이 더 높은 가치의 판단 업무나 관계 형성에 쓰이고 있다면, 그것이 진짜 워크플로우 재설계가 성공한 증거입니다.

## 워크플로우 재설계 인터랙티브 개념도 — 구조 요약

**4개 레이어로 구성된 전체 구조**는 이렇습니다.

**1층: 재설계 대상 업무 3군**

군 A(즉시 자동화) — 정보 수집·정리·배포형. 판단이 거의 없고 형식이 고정된 업무. 회의록 요약, 주간 보고 취합, 설문 결과 정리가 여기 속하며 MS Copilot이 1차 진입로입니다.

군 B(AI 증강) — 판단 보조·분석형. 인간의 판단 품질을 AI가 끌어올리는 방식. 역량 진단 해석, 인터뷰 질문 생성, 교육 대상 우선순위화. AntiGravity Manager View가 적합합니다.

군 C(Vibe-Coding 자동화) — 산출물 생성·패키징형. AX 성숙도 리포트, Pulse Check 대시보드, 교육 자료 초안. Claude Code와 Lovable이 담당합니다.

**2층: AI Agent 적용 3층 레이어**

Layer 1(침투) → Layer 2(심화) → Layer 3(내재화)의 순서로, 군 A는 Layer 1과, 군 B는 Layer 2와, 군 C는 Layer 3과 자연스럽게 매핑됩니다.

**3층: 10주 스프린트** — 해부(W1-2) → 실험(W3-4) → 정제(W5-6) → 확장(W7-8) → 공유(W9-10)

**4층: 성과 측정** — 생산성 10% 개선 / AX 성숙도 +15% / 행동 전염 지수 → 최종 AX 내재화 성공 증거로 수렴
