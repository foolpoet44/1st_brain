## 현실 진단: "무료 모델로 자동 전환"은 아직 공식 기능이 아니다

GitHub Issue #2944에 올라온 Feature Request를 보면, 사용량 초과 시 API 키로 자동 Fallback하는 설정(JSON config 방식)은 현재 제안 단계이고 공식 구현은 되어 있지 않습니다. 즉 "한도 초과 → 무료 모델로 자동 전환"을 기대했다면, 완전 자동은 아직입니다.

하지만 **3가지 실용적 전략**으로 끊김 없는 빌드 지속은 충분히 가능합니다.

---

## 전략 1: settings.json으로 모델 계층 미리 설계하기

Claude Code의 `settings.json`에서 `availableModels`와 `ANTHROPIC_DEFAULT_*_MODEL` 환경변수를 조합하면 사용 가능한 모델 풀을 제한하고, 기본 해상도를 Sonnet이나 Haiku로 내려놓을 수 있습니다.

```json
// ~/.claude/settings.json
{
  "model": "claude-sonnet-4-6",
  "availableModels": ["claude-sonnet-4-6", "haiku"],
  "env": {
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-6",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5-20251001"
  }
}
```

이 설정의 의미는 Opus를 아예 선택지에서 제거하고, 평소엔 Sonnet, 간단한 작업은 Haiku로 손수 라우팅하겠다는 선언입니다. Max/Team Premium 플랜은 기본값이 Opus 4.6이기 때문에, Opus 사용량을 의도치 않게 소진하고 있을 가능성이 높습니다.

---

## 전략 2: OpenRouter 무료 모델을 Fallback으로 연결하기

이것이 CSP의 "끊김 없는 빌드 지속" 목표에 가장 가까운 접근법입니다.

`free-claude-code` 같은 오픈소스 프록시를 사용하면 Opus/Sonnet/Haiku 요청을 각각 다른 provider로 라우팅할 수 있고, OpenRouter의 무료 티어 모델(`:free` suffix)을 Fallback으로 설정할 수 있습니다.

`.env` 예시:

```bash
OPENROUTER_API_KEY="sk-or-..."

# 평소 사용
MODEL_SONNET="open_router/openai/gpt-oss-120b:free"

# 한도 초과 시 Fallback
MODEL_HAIKU="open_router/stepfun/step-3.5-flash:free"
MODEL="open_router/stepfun/step-3.5-flash:free"  # 최종 Fallback
```

이 구조는 Anthropic 사용량이 초과되면 OpenRouter 무료 모델이 자동으로 받아치는 구조입니다.

---

## 전략 3: Subagent별 모델 분리 (가장 스마트한 방법)

Claude Code의 subagent 정의 파일에서 각 agent마다 다른 모델을 지정할 수 있습니다. 예를 들어 코드 리뷰 agent는 Sonnet, 단순 파일 탐색 agent는 Haiku로 각각 설정하는 것이 가능합니다.

```markdown
---
name: code-reviewer
model: sonnet
---
```

```markdown
---
name: file-explorer
model: haiku
---
```

CSP처럼 여러 프로젝트(ESCON, Pulse Check, EX Intelligence)를 병렬로 돌리는 환경에서는 **무거운 판단 작업은 Sonnet, 파일 읽기·단순 검색은 Haiku**로 라우팅하는 것만으로도 사용량이 체감적으로 크게 줄어듭니다.

---

## 추가로 알아야 할 현실적 버그

Anthropic도 공식 인정했듯이, Claude Code의 prompt cache가 깨지는 버그가 있어 실제보다 10-20배 많은 토큰이 소진되는 사례가 보고됐습니다. 버전 다운그레이드(2.1.34)로 개선됐다는 유저 보고도 있습니다. 이상하게 빨리 한도가 차는 느낌이라면 버전 확인이 먼저입니다.

---

**요약하면**: 완전 자동 무료 전환은 공식 미지원이지만, `settings.json`으로 모델 계층을 설계하고 + OpenRouter 무료 모델을 Fallback provider로 연결하는 조합이 현재 가장 현실적인 "빌드 무중단" 구성입니다. ESCON이나 Pulse Check 같은 프로젝트에 적용해보실 의향이 있으시면 구체적인 설정 파일 작성을 같이 해드릴 수 있습니다.
