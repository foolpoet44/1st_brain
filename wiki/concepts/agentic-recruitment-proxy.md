# Agentic Recruitment Proxy (에이전틱 채용 대리인)

> "채용의 권력은 이제 '사람의 직관'에서 '에이전트의 검증된 데이터 리포트'로 이동합니다."

## 1. 개념: 판단의 외주화

Harper와 같은 AI 탤런트 에이전트의 등장은 구직 활동의 자동화를 넘어, 채용 프로세스 내 **'신뢰의 주체'**가 바뀌는 현상입니다.

- **Legacy**: 후보자의 이력서(Self-Report) -> 인사팀의 서류 검토 -> 면접.
- **Agentic**: 에이전트와의 상호작용 -> 검증된 역량 데이터 리포트 생성 -> 면접/채용 확정.

## 2. 핵심 변곡점: 데이터 임계점 (Threshold)

- **모니터링 지표**: 에이전트를 통해 채용된 인원의 **'6개월 유지율 및 성과 데이터'**.
- **판단의 종말**: 에이전트의 선발 정확도가 인간을 상회하는 임계점을 넘는 순간, 전통적인 잡보드(LinkedIn 등)와 서류 검토 프로세스는 폐기됩니다.

## 3. HR 전략적 함의

- **인사팀의 역할 변화**: '누구를 뽑을 것인가'를 고민하는 조직에서 '어떤 에이전트의 로직을 신뢰하고 시스템화할 것인가'를 설계하는 조직으로 변화해야 함.
- **에이전트 거버넌스**: 에이전트가 생성한 데이터 리포트의 편향성을 검증하고, 조직 문화와의 적합성을 판단하는 고차원적 로직 설계가 필요함.
