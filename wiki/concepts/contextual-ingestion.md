# Contextual Ingestion (맥락적 적재)

지식 체계가 에이전트의 실제 '지능'으로 작동하기 위해서는 파편화된 정보가 아니라, 흐르는 **'맥락(Context)'**이 실시간으로 적재되어야 합니다.

- **AI-Readable Structure**: 슬랙 대화나 회의록은 발생 즉시 마크다운으로 변환되어야 함.
- **Unconscious Stacking**: 사용자가 수동으로 업로드하는 것이 아니라, Zapier 등의 자동화 도구를 통해 에이전트의 메모리에 자동으로 쌓여야 함 (복리의 마법).
- **Security First**: 맥락이 깊어질수록 보안 노출의 위험도 커지므로, '열람 권한'에 근거한 데이터 격리 아키텍처가 필수적임.
