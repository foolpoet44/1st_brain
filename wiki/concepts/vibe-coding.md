# Vibe Coding

## Compiled Truth

AI 와 함께 **흐름 (Vibe)**에 맡려서 코딩하는 방식.

**핵심 특징:**

- 상세 설계 없이 AI 와 대화하며 점진적으로 구현
- "왜"보다 "무엇을"에 집중 — AI 가 "어떻게"를 처리
- 인간은 방향성과 문맥을 제공하고, AI 가 구현 디테일 처리
- SW 공학 백그라운드가 없는 도메인 전문가도 코드 작성 가능

**CSP 의 Vibe Coding 정의:**

> 심리학과 HR 경험을 코드로 변환하는 작업. 기술적 디테일은 AI 에게 맡기고, 인간은 도메인 통찰과 사용자 경험에 집중.

[[Self-Determination Theory (자기결정이론)|자기결정이론]] 과 연결하면 — Vibe Coding 은 **자율성** (내가 방향을 정함) 과 **유능감** (AI 도움으로 내가 만드는 것) 을 동시에 충족.
