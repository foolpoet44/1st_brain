# Weak Signal Theory (Ansoff)

## Compiled Truth

H. Igor Ansoff 가 제안한 개념으로, 환경의 급격한 변화가 닥치기 전 발생하는 불완전하고 단편적인 정보를 의미합니다. CSP Brain 은 조직 내 EX(Employee Experience) 의 붕괴나 혁신의 기회를 이 '약한 신호'단계에서 포착하는 것을 목표로 합니다.

**신호의 단계 (The Levels of Signals)**

| Level   | 설명                                                           |
| :------ | :------------------------------------------------------------- |
| Level 1 | 뭔가 일어나고 있다는 막연한 느낌 (Sense of threat/opportunity) |
| Level 2 | 위협이나 기회의 출처와 성격이 어느 정도 파악됨                 |
| Level 3 | 구체적인 형태와 파급력이 보이기 시작함                         |
| Level 4 | 대응 전략을 수립할 수 있을 만큼 명확해짐 (Actionable strategy) |

**CSP Brain 에서의 활용**

조직 개발 (OD) 맥락에서 Weak Signal 은 다음과 같은 형태로 나타납니다:

- 핵심 인재의 비정형 메시지 톤 변화 (L3 Sensing)
- 특정 부서의 협업 도구 사용 패턴 급감 (L2 Sensing)
- 익명 피드백에서의 반복되는 특정 단어 (Keyword) 의 부상

**전략적 시사점**

- **Proactive Intervention**: 신호가 Level 4 가 되어 누구나 알게 되었을 때는 이미 늦습니다. CSP Brain 은 L1~L2 단계의 약한 신호를 포착하여 선제적 개입 (Intervention) 을 가능케 합니다.
- **Sense-making**: 산재된 데이터 조각들을 LLM 을 통해 엮어내어 의미 있는 패턴 (Pattern Recognition) 으로 변환하는 과정이 핵심입니다.
