# [SIGNAL] DB 스키마의 지식 자산화: td-export와 Git-Ops

## 핵심 요약
- **문제 의식**: 테이블 정의서는 실제 DB와 늘 괴리되어 있음.
- **해결책**: `td-export` 도구를 통해 DB의 메타데이터를 직접 읽어 Markdown/SQL 등으로 자동 추출하여 Git에 관리.
- **효과**: 신규 입사자 온보딩 자동화 및 PR 단계에서 스키마 변화 가시화.

## CSP-Brain 적용
- 지식의 '사회화' 프로토콜: 내부 데이터베이스나 노션의 상태를 텍스트로 뽑아내어 Git 리포에 동기화하는 것이 진정한 AI-Native 조직의 데이터 대사 작용임.
