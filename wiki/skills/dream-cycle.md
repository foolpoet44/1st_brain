# Dream Cycle (주간 정리 루틴)

## Compiled Truth

매주 금요일 실행하는 메모리 정리 루틴입니다. 뇌의 수면 중 기억 강화 과정에서 영감을 받은 패턴입니다.

**실행 단계**

1. **inbox 정리**
   - `inbox/` 전체 스캔
   - 각 항목을 적절한 폴더로 이동
     - 프로젝트 관련 → 해당 `projects/` Timeline 에 append
     - 인물 관련 → `wiki/people/` 파일 생성 또는 업데이트
     - 개념/이론 → `wiki/concepts/` 파일 생성
     - 결정 → `wiki/decisions/` 파일 생성

2. **Compiled Truth 갱신**
   - 이번 주 변화가 있던 프로젝트 파악
   - 각 프로젝트 README 의 Compiled Truth 업데이트

3. **Weekly 파일 생성**
   - 파일명: `outputs/weekly/YYYY-WNN.md`
   - 포함 내용: 핵심 활동, 주요 결정, 다음 주 액션

4. **inbox 초기화**
   - 처리 완료된 항목 제거
   - 마지막 Dream Cycle 날짜 업데이트

**주의사항**

- Timeline 에는 절대 손대지 않음 (append 만 허용)
- Compiled Truth 갱신 시 이전 내용을 덮어씀 (의도적)
- 모든 inbox 항목을 처리하려 하지 말 것 — 분류 불명확하면 그냥 두기
