# Memory Save (대화 종료 기록)

## Compiled Truth

대화 종료 후 핵심 내용을 Brain 에 기록하는 절차입니다.

**실행 단계**

1. **핵심 결정사항 추출** — 대화에서 이루어진 주요 결정 식별
2. **프로젝트 갱신** — 관련 프로젝트 README 의 Timeline 에 새 항목 추가
3. **개념 문서 생성/수정** — 새로운 개념이 나왔으면 wiki/concepts/ 에 문서 생성
4. **inbox 에 기록** — 처리가 필요한 항목이 있으면 inbox/ 에 추가

**주의사항**

- Timeline 에는 항상 날짜와 함께 기록
- Compiled Truth 는 필요한 경우에만 갱신 (매번 아님)
