# Claude Code

## Compiled Truth

Anthropic 의 Claude 모델과 연동된 CLI 기반 코딩 에이전트.

**주요 기능:**

- 터미널에서 직접 코드 읽기/쓰기/실행
- Git 연동 (커밋, PR 생성)
- 프로젝트 구조 이해 및 수정
- 테스트 실행 및 디버깅

**CSP 활용 맥락:**

- csp-brain Vault 의 지식 운영 에이전트
- INGEST, LINT, DIGEST, BRIDGE 프로토콜 실행
- [[Vibe Coding]] 의 주요 도구
