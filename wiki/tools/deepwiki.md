# DeepWiki

AI 소프트웨어 엔지니어 'Devin'으로 유명한 Cognition Labs가 개발한 AI 기반 코드 문서화 도구.

## 개요

GitHub 공개 저장소의 URL만 입력하면, AI가 해당 코드베이스의 구조와 로직을 분석해 위키 형태의 구조화된 문서를 자동으로 생성해 줍니다.

## 주요 기능

1. **저장소 구조 및 아키텍처 개요**: 전체 시스템의 조감도 제공.
2. **기술 스택 식별**: 사용된 라이브러리와 언어 자동 파악.
3. **시각화 다이어그램**: Mermaid를 활용한 모듈 간 의존성 및 데이터 흐름 시각화.
4. **자연어 Q&A (Ask)**: "인증은 어디서 처리하나요?" 같은 질문에 코드 기반 답변.
5. **표준 섹션 생성**: Overview, St[[Understand-Anything/understand-anything-plugin/skills/understand/locales/ru.md|ru]]cture, Architecture, API, Subsystems, Operations, Testing, Glossary 등 8개 섹션.

## 변체 (Variants)

- **DeepWiki (SaaS)**: 공식 서비스. 공개 저장소 무료.
- **deepwiki-op[[Understand-Anything/understand-anything-plugin/skills/understand/locales/en.md|en]]**: 커뮤니티 오픈소스 버전. 로컬 LLM(Ollama 등) 연동 및 비공개 저장소 지원.
