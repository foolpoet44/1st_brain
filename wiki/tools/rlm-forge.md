# RLM-Forge (Q00/rlm-forge)

## Compiled Truth

RLM(Recursive Language Model) 패러다임 — 모델이 컨텍스트를 한 번에 삼키는 대신 **스스로를 재귀 호출해 무한 컨텍스트를 조각내 처리**하는 구조 — 의 실험 구현 리포지토리. 2026-06-16 지식 체계에 통합된 RLM 개념([[graph-rag]]의 레이지 추론과 같은 계보)의 실행 도구 후보다.

CSP 관점의 함의: csp-brain 이 위키를 통째로 읽지 않고 인덱스→문서로 파고드는 방식이 이미 RLM 적 접근이다. [[durable-execution]]과 결합하면 "중단돼도 이어지는 재귀 지식 탐색"이 가능해진다.
